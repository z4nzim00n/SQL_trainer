# Задание 01. Топ-N и сортировка результата топа

Нужно две сортировки: сначала **отбор** лучших по количеству, потом **вывод** по имени. Один `ORDER BY` с `LIMIT` решает только первое: он оставит четырёх лучших, но выдаст в порядке количества.

Поэтому топ делают внутри подзапроса (с `ORDER BY ... LIMIT 4`), а внешний запрос сортирует его результат по имени:

```sql
SELECT name, count_of_visits
FROM (SELECT ... ORDER BY count_of_visits DESC, name LIMIT 4) AS top
ORDER BY name;
```

`LIMIT n` оставляет первые `n` строк **после** сортировки. Если при равенстве количества не указать вторым ключом имя, какой из «равных» попадёт в топ, неопределённо.

Группировать лучше по `person.id` и `person.name`: так два разных человека с одинаковым именем не сольются в одну группу.

Ключевые слова для примеров: `LIMIT`, `GROUP BY`, `COUNT`, `JOIN`, `ORDER BY`.
