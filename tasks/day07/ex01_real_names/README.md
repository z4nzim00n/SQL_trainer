# Задание 01. Посмотрим на настоящие имена

**Разрешено:** ANSI SQL

Измени запрос из задания 00 так, чтобы он возвращал **имя** человека (`name`), а не идентификатор. Дополнительное условие: нужно вывести только **топ-4 человека** с наибольшим количеством визитов во все пиццерии, а сам список отсортировать **по имени** человека.

Если у нескольких людей одинаковое число визитов и они борются за последнее место в топе, выбирай того, кто идёт **раньше по алфавиту**.

| name | count_of_visits |
| --- | --- |
| Dmitriy | 4 |
| Denis | 3 |
| … | … |
