# Задание 03. Статистика по ресторанам, часть 2

**Разрешено:** ANSI SQL

Покажи, как рестораны группируются по количеству посещений и по количеству заказов, и объедини эти данные **по названию пиццерии**. Можно использовать внутренний запрос из задания 02 **без** ограничения на количество строк (то есть все пиццерии, а не топ-3).

Правила:

- вычисли общую сумму заказов и посещений для каждой пиццерии (не все пиццерии могут быть в обеих таблицах);
- отсортируй результат по `total_count` по убыванию, затем по `name` по возрастанию.

Столбцы результата: `name`, `total_count`.

| name | total_count |
| --- | --- |
| Dominos | 13 |
| DinoPizza | 9 |
| … | … |
