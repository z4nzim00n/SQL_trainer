# Задание 08. Группировка по двум столбцам

`GROUP BY` может принимать несколько столбцов: группой становится **уникальная пара** (или тройка) значений. Здесь группа: (адрес человека, название пиццерии). Агрегат `COUNT(*)` считает заказы внутри каждой такой пары.

Адрес лежит в `person`, название пиццерии в `pizzeria`, а соединяет их заказ: `person_order → person` и `person_order → menu → pizzeria`.

Всё, что в `SELECT` не агрегат, должно быть и в `GROUP BY`: `person.address` и `pizzeria.name`.

Сортировка по двум ключам: `ORDER BY person.address, pizzeria.name`.

Ключевые слова для примеров: `GROUP BY`, `COUNT`, `JOIN`, `ORDER BY`.
