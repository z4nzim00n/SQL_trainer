# Задание 08. Найдём точки пиццерий по городам

**Разрешено:** ANSI SQL

Известны личные адреса людей. Предположим, что человек посещает только пиццерии **в своём городе**, то есть заказы по адресу людей относят к городу пиццерии.

Напиши запрос, который возвращает:

- адрес (`address`);
- название пиццерии (`name`);
- общее количество заказов (`count_of_orders`) в этой пиццерии людьми с этим адресом.

Отсортируй результат сначала по адресу, затем по названию заведения.

| address | name | count_of_orders |
| --- | --- | --- |
| Kazan | Best Pizza | 4 |
| Kazan | DinoPizza | 4 |
| … | … | … |
