# Задание 00. Простая агрегация

**Разрешено:** ANSI SQL

Выполним простую агрегацию. Напиши запрос, который возвращает идентификаторы людей (`person_id`) и соответствующее **количество посещений** любых пиццерий (`count_of_visits`).

Отсортируй результат по количеству посещений по **убыванию**, а затем по `person_id` по **возрастанию**.

| person_id | count_of_visits |
| --- | --- |
| 9 | 4 |
| 4 | 3 |
| … | … |
