# Задание 00. GROUP BY и COUNT

**Агрегатные функции** сворачивают много строк в одно значение: `COUNT` (количество), `SUM` (сумма), `AVG` (среднее), `MIN`, `MAX`.

Без `GROUP BY` агрегат считается по всей таблице и даёт одну строку. С `GROUP BY` таблица делится на **группы** по значению указанного столбца, и агрегат считается отдельно по каждой группе:

```sql
SELECT person_id, COUNT(*) FROM person_visits GROUP BY person_id;
```

`COUNT(*)` считает строки группы, то есть посещения каждого человека. Столбцу с агрегатом нужно дать имя через `AS`.

Правило: всё, что стоит в `SELECT` и не является агрегатом, должно быть перечислено в `GROUP BY`.

В `ORDER BY` можно перечислять несколько ключей с разными направлениями: `ORDER BY count_of_visits DESC, person_id ASC`: сначала по убыванию числа, при равенстве по возрастанию номера.

Ключевые слова для примеров: `GROUP BY`, `COUNT`, `AS`, `ORDER BY`, `DESC`, `ASC`.
