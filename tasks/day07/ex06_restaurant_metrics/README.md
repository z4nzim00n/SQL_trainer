# Задание 06. Метрики ресторанов

**Разрешено:** ANSI SQL

Напиши запрос, который возвращает **для каждой пиццерии**:

- общее количество заказов (`count_of_orders`),
- среднюю цену (`average_price`),
- максимальную цену (`max_price`),
- минимальную цену (`min_price`) на заказанные пиццы.

Результат отсортируй по названию пиццерии (`name`). Среднюю цену округли до **двух** знаков после запятой.

| name | count_of_orders | average_price | max_price | min_price |
| --- | --- | --- | --- | --- |
| Best Pizza | 5 | 780 | 850 | 700 |
| DinoPizza | 5 | 880 | 1000 | 800 |
| … | … | … | … | … |
