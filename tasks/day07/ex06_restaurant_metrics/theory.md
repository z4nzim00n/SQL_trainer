# Задание 06. Несколько агрегатов в одном запросе

В одном `SELECT` можно считать сразу много агрегатов по одной группировке: `COUNT(*)`, `AVG(...)`, `MAX(...)`, `MIN(...)`.

- `AVG(menu.price)`: среднее значение, обычно с длинным «хвостом» (`783.3333…`);
- `ROUND(x, 2)`: округление до двух знаков после запятой;
- `MAX`, `MIN`: наибольшее и наименьшее значение в группе.

**Цены берутся из заказов, а не из всего меню:** нужны «цены на проданные пиццы». Поэтому в запросе таблица `person_order` связывается с `menu`, а не наоборот: каждая строка заказа приносит цену одной заказанной пиццы. Если взять `menu` целиком, в среднюю цену попадут и те пиццы, которые не заказывали.

Пиццерии без заказов в результат не попадают: к ним нечего сворачивать.

Ключевые слова для примеров: `COUNT`, `AVG`, `MAX`, `MIN`, `ROUND`, `GROUP BY`.
