# Задание 04. Условие для групп

**Разрешено:** ANSI SQL

**Запрещено:** `WHERE`

Напиши запрос, который возвращает **имя человека** и **количество его посещений** любых пиццерий при условии, что количество **больше 3** (`> 3`). Столбцы: `name`, `count_of_visits`.

| name | count_of_visits |
| --- | --- |
| Dmitriy | 4 |

> На небольших учебных данных запрос может вернуть пустую таблицу: на основных данных мало людей с таким числом визитов. Тренажёр сверяет ответ ещё и на другом наборе данных, где такие люди есть.
