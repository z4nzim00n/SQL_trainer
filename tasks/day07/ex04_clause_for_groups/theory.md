# Задание 04. HAVING

`WHERE` фильтрует **строки до группировки**, а условие на **результат агрегата** (например, «количество больше 3») поставить в `WHERE` нельзя: агрегат ещё не посчитан. Для этого есть `HAVING`: он фильтрует **группы после группировки**.

```sql
SELECT person_id, COUNT(*)
FROM person_visits
GROUP BY person_id
HAVING COUNT(*) > 3;
```

Порядок выполнения: `FROM`/`JOIN` → `WHERE` → `GROUP BY` → агрегаты → `HAVING` → `SELECT` → `ORDER BY`.

Внутри `HAVING` можно использовать только агрегаты и столбцы из `GROUP BY`. Псевдонимы из `SELECT` в нём, как правило, недоступны, поэтому условие повторяют: `HAVING COUNT(*) > 3`.

Ключевые слова для примеров: `HAVING`, `GROUP BY`, `COUNT`.
