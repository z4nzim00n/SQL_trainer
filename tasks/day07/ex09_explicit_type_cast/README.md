# Задание 09. Явное преобразование типов

**Разрешено:** ANSI SQL

Напиши запрос, который возвращает агрегированную информацию по **адресу** каждого человека. В результат включи:

- `formula`: значение «максимальный возраст − (минимальный возраст / максимальный возраст)», округлённое до 2 знаков;
- `average`: средний возраст по адресу, округлённый до 2 знаков;
- `comparison`: результат сравнения формулы и среднего возраста: `true`, если значение формулы **больше** среднего, иначе `false`.

Результат отсортируй по столбцу с адресом (`address`).

| address | formula | average | comparison |
| --- | --- | --- | --- |
| Kazan | 44.71 | 30.33 | true |
| Moscow | 20.24 | 18.5 | true |
| … | … | … | … |
