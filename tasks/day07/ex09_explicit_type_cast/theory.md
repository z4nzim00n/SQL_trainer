# Задание 09. Целочисленное деление и приведение типов

В PostgreSQL деление целого на целое тоже даёт **целое число**: `18 / 21` равно `0`, а не `0.857…`. Возраст у нас целого типа, поэтому формула `MIN(age) / MAX(age)` без подготовки потеряет дробную часть.

Решение: явно привести один из операндов к `numeric`:

```sql
MIN(age)::numeric / MAX(age)      -- 0.857...
CAST(MIN(age) AS numeric) / MAX(age)   -- то же самое
```

Теперь формула `MAX(age) - MIN(age)::numeric / MAX(age)` считается точно. Приоритет операций: деление выполняется раньше вычитания, скобки здесь нужны только для читаемости.

Сравнение `формула > AVG(age)` возвращает `true` или `false`. Выражение сравнения можно писать прямо в `SELECT`, давая ему имя через `AS`.

Заметь: в `SELECT` нельзя сослаться на псевдоним `formula` в соседнем выражении, поэтому формулу пишут заново.

Ключевые слова для примеров: `::`, `CAST`, `ROUND`, `AVG`, `MAX`, `MIN`, `GROUP BY`.
