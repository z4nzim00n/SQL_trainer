# Задание 05. Уникальность людей

**Разрешено:** ANSI SQL

**Запрещено:** `GROUP BY`, а также любые операторы работы с множествами (`UNION`, `EXCEPT`, `INTERSECT`)

Напиши простой запрос, который возвращает список **уникальных имён** людей, сделавших хотя бы один заказ в любой пиццерии. Отсортируй результат по имени. Столбец: `name`.

| name |
| --- |
| Andrey |
| Anna |
| … |
