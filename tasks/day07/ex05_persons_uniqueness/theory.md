# Задание 05. DISTINCT

Если человек сделал несколько заказов, после `JOIN` его имя встретится несколько раз. Чтобы оставить каждое значение один раз, используют `SELECT DISTINCT`.

```sql
SELECT DISTINCT name FROM ...;
```

`DISTINCT` убирает повторяющиеся **строки целиком**. Если в `SELECT` несколько столбцов, уникальной должна быть их комбинация.

Это альтернатива `GROUP BY` без агрегата: `SELECT DISTINCT name` и `SELECT name ... GROUP BY name` дают одинаковый результат. Здесь `GROUP BY` запрещён, поэтому используем `DISTINCT`.

Тот же результат даёт `EXISTS` (человек, для которого существует заказ): тогда строки не размножаются и `DISTINCT` не нужен.

Ключевые слова для примеров: `DISTINCT`, `EXISTS`, `JOIN`, `ORDER BY`.
