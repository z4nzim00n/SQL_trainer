# Задание 02. Два топа в одном списке

Здесь нужно получить два отдельных топ-3 и склеить их.

Каждый топ это запрос с `GROUP BY` названию пиццерии, `ORDER BY ... DESC` и `LIMIT 3`. Различать их помогает **константный столбец**: `'order' AS action_type` в первом запросе и `'visit' AS action_type` во втором.

Склеивает результаты `UNION ALL`. Так как у каждого запроса есть собственные `ORDER BY` и `LIMIT`, их нужно взять в **скобки**; общая сортировка `ORDER BY action_type, count DESC` пишется в самом конце, после последней скобки.

Заказы связаны с пиццерией через `menu`: `person_order → menu → pizzeria`. Посещения связаны напрямую: `person_visits → pizzeria`.

Ключевые слова для примеров: `UNION ALL`, `LIMIT`, `GROUP BY`, `COUNT`, `AS`.
