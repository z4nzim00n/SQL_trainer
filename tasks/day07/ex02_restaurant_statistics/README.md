# Задание 02. Статистика по ресторанам

**Разрешено:** ANSI SQL

Напиши запрос, который выводит **топ-3 самых популярных заведения по количеству заказов** и **топ-3 по количеству посещений**, объединив результаты в один список.

Добавь столбец `action_type` со значением `'order'` (данные из заказов) или `'visit'` (данные из посещений). Столбцы результата: `name`, `count`, `action_type`.

Итог отсортируй по `action_type` по возрастанию и по `count` по убыванию.

При равенстве количества в борьбе за место в топе выбирай заведение с меньшим названием по алфавиту.

| name | count | action_type |
| --- | --- | --- |
| Dominos | 6 | order |
| … | … | … |
| Dominos | 7 | visit |
| … | … | … |
