# Задание 08. DROP для представлений

Представление удаляют командой `DROP VIEW имя;`, а материализованное: `DROP MATERIALIZED VIEW имя;`. Это **разные** команды: обычный `DROP VIEW` на материализованное представление выдаст ошибку.

Можно перечислить несколько обычных представлений через запятую: `DROP VIEW a, b, c;`.

Удаляются только представления, а таблицы и данные в них остаются целыми. Опасный вариант `DROP TABLE ... CASCADE` удалил бы и таблицу, и всё, что от неё зависит: так делать не нужно.

Ключевые слова для примеров: `DROP`, `VIEW`, `MATERIALIZED VIEW`.
