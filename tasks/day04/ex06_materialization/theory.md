# Задание 06. MATERIALIZED VIEW

Обычное представление хранит **запрос**, а **материализованное** хранит **результат** этого запроса, как «снимок» данных на момент создания.

```sql
CREATE MATERIALIZED VIEW имя AS
SELECT ...
WITH DATA;
```

- `WITH DATA`: сразу выполнить запрос и сохранить строки;
- `WITH NO DATA`: создать пустым, читать нельзя до первого обновления.

Плюс: чтение мгновенное, тяжёлый запрос не пересчитывается. Минус: данные могут устареть, пока их не обновят командой `REFRESH MATERIALIZED VIEW` (следующее задание).

Ключевые слова для примеров: `MATERIALIZED VIEW`, `REFRESH`, `CREATE VIEW`.
