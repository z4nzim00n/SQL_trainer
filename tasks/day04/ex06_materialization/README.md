# Задание 06. Материализация из виртуализации

**Разрешено:** ANSI SQL

Создай **материализованное представление** `mv_dmitriy_visits_and_eats` (**с данными**) на основе запроса, который находит название пиццерии, где `Dmitriy` был **8 января 2022 года** и мог съесть пиццу **дешевле 800** рублей. Этот запрос ты писал в Day 02 (задание 07). Столбец результата: `pizzeria_name`.

Для самопроверки выполни запрос к `mv_dmitriy_visits_and_eats` и сравни результат с исходным запросом.
