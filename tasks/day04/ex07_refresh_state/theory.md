# Задание 07. REFRESH MATERIALIZED VIEW

Материализованное представление хранит снимок и **само не обновляется**. Если добавить визит в `person_visits`, снимок останется прежним, пока его не обновят:

```sql
REFRESH MATERIALIZED VIEW имя;
```

Команда пересчитывает запрос и заменяет сохранённые строки новыми.

Порядок: сначала меняем исходные данные (`INSERT`), потом обновляем снимок. Если сделать наоборот, в снимок ничего нового не попадёт.

`id` визита вычисляем как `MAX(id) + 1`, человека и пиццерию находим подзапросами по имени.

Ключевые слова для примеров: `REFRESH`, `MATERIALIZED VIEW`, `INSERT`, `MAX`.
