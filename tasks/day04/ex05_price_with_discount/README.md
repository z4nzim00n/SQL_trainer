# Задание 05. Цена со скидкой для каждого

**Разрешено:** ANSI SQL, `round(...)`

Создай представление `v_price_with_discount`, которое возвращает заказы людей с указанием:

- имени клиента (`name`),
- названия пиццы (`pizza_name`),
- реальной цены (`price`),
- столбца `discount_price`: цена с 10% скидкой по формуле `price - price * 0.1`.

Отсортируй результат по имени клиента и названию пиццы. Столбец `discount_price` округли до целого числа.

| name | pizza_name | price | discount_price |
| --- | --- | --- | --- |
| Andrey | cheese pizza | 800 | 720 |
| Andrey | mushroom pizza | 1100 | 990 |
| … | … | … | … |
