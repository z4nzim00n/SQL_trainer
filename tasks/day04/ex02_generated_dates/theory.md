# Задание 02. Представление над генератором

`generate_series(начало, конец, шаг)` создаёт ряд значений. Для дат нужен шаг-интервал: `generate_series('2022-01-01'::date, '2022-01-31'::date, '1 day'::interval)`. Но в PostgreSQL для такого вызова результат имеет тип `timestamp`, поэтому приводим к дате: `::date`.

Столбцу нужно имя: `AS generated_date`. Сортировка `ORDER BY` допустима прямо в определении представления.

Такое представление удобно как «календарь»: его соединяют с реальными данными, чтобы найти пропуски (это задание 03).

Ключевые слова для примеров: `GENERATE_SERIES`, `CREATE VIEW`, `::`, `ORDER BY`.
