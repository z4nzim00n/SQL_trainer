# Задание 00. Раздельные представления для людей

**Разрешено:** ANSI SQL

Создай два представления (с теми же атрибутами, что и у исходной таблицы `person`), которые фильтруют людей по полу. Дай представлениям имена:

- `v_persons_female`: для лиц женского пола;
- `v_persons_male`: для лиц мужского пола.

> В тренажёре создание представления откатывается после проверки. Тренажёр сам обращается к твоим представлениям и сравнивает их содержимое с эталоном.
