# Задание 00. Представление (VIEW)

**Представление** это сохранённый запрос с именем. Данных оно само не хранит: каждый раз, когда к нему обращаются, запрос выполняется заново на актуальных таблицах. Обращаться к нему можно как к обычной таблице: `SELECT * FROM имя_представления`.

```sql
CREATE VIEW имя AS
SELECT ... FROM ... WHERE ...;
```

`SELECT *` в определении берёт все столбцы таблицы на момент создания, поэтому у представления те же атрибуты, что у `person`.

Зачем: спрятать сложный запрос за коротким именем, ограничить доступ к части данных (например, показать только одну группу людей), не дублировать одну и ту же логику в нескольких местах.

Ключевые слова для примеров: `CREATE VIEW`, `VIEW`, `WHERE`.
