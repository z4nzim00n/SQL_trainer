# Задание 10. Ещё один INSERT ... SELECT

Задача устроена так же, как задание 09, но вставляем строки в `person_order`: `id`, человек, меню и дата.

Номер меню получаем подзапросом, который возвращает одно значение: `(SELECT id FROM menu WHERE pizza_name = 'sicilian pizza')`. Он работает, пока название в меню уникально.

Идея с `MAX(id) + person.id` даёт уникальные `id`: у разных людей разные `person.id`, а `MAX` берётся один раз до вставки (во всех строках одно и то же значение).

Ключевые слова для примеров: `INSERT`, `MAX`.
