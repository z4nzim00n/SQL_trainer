# Задание 10. Новые визиты: новые заказы

**Разрешено:** ANSI SQL

**Запрещено:** прямые числовые значения для идентификатора первичного ключа, людей и меню

Зарегистрируй заказы `Denis` и `Irina` на **24 февраля 2022 года** на новую позицию меню `sicilian pizza`. Идентификатор меню получи подзапросом по названию, `id` заказов вычисли динамически.

> Задание изменяет данные (в тренажёре они откатываются).
