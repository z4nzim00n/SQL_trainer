# Задание 02. Забытые пиццы и пиццерии

**Разрешено:** ANSI SQL

Используй запрос из задания 01 и выведи названия пицц, которые никто не заказывал, вместе с ценами и названиями пиццерий.

Результат отсортируй по названию пиццы и цене. Столбцы: `pizza_name`, `price`, `pizzeria_name`.

| pizza_name | price | pizzeria_name |
| --- | --- | --- |
| cheese pizza | 700 | Papa Johns |
| cheese pizza | 780 | DoDo Pizza |
| … | … | … |
