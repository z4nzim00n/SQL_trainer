# Задание 07. Сварим новый вид пиццы

**Разрешено:** ANSI SQL

Добавь в меню новую пиццу `greek pizza` с идентификатором **19** по цене **800** рублей в пиццерию `Dominos` (её `pizzeria_id = 2`).

> Это задание изменяет данные. В тренажёре каждый запрос выполняется в откатываемой транзакции, поэтому база не портится. На настоящей базе (DataGrip, psql) такой `INSERT` изменит данные навсегда: для восстановления выполни исходный скрипт.

Проверяется, что в таблице `menu` после запроса нужное состояние.
