## Идея

Нужна одна строка в `menu`. Четыре значения: `id`, `pizzeria_id`, название и цена.

## Каркас

```sql
INSERT INTO menu (id, pizzeria_id, pizza_name, price)
VALUES (______, ______, '______', ______);
```

## Почти ответ

```sql
INSERT INTO menu (id, pizzeria_id, pizza_name, price)
VALUES (19, 2, 'greek pizza', ______);
```

Осталась цена.
