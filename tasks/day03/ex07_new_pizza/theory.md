# Задание 07. INSERT

`INSERT INTO таблица VALUES (...)` добавляет строку. Значения идут в порядке столбцов таблицы: `id`, `pizzeria_id`, `pizza_name`, `price`. Надёжнее перечислить столбцы явно: `INSERT INTO menu (id, pizzeria_id, pizza_name, price) VALUES (...)`: так порядок не зависит от устройства таблицы.

Текст пишется в одинарных кавычках. Если нарушить правила таблицы (повторить `id`, указать несуществующую пиццерию), база вернёт ошибку.

Чтобы увидеть результат, добавь после вставки `SELECT * FROM menu` или используй `RETURNING *` в самом `INSERT`.

Ключевые слова для примеров: `INSERT`, `RETURNING`.
