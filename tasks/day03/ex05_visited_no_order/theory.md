# Задание 05. Посетил, но не заказал

Нужны два множества названий пиццерий для одного человека:

- **посещённые**: из `person_visits`;
- **заказанные**: из `person_order` через `menu` (в заказе хранится только меню, а пиццерию даёт `menu.pizzeria_id`).

Ответ это первое множество без второго: оператор разности `EXCEPT`. Он убирает повторы, поэтому каждая пиццерия встретится один раз. Оба запроса должны выбирать один столбец одного типа, а `ORDER BY` пишется один раз в конце.

Как вариант, то же даёт `NOT IN` или `NOT EXISTS`.

Ключевые слова для примеров: `EXCEPT`, `JOIN`, `NOT IN`, `ORDER BY`.
