# Задание 09. INSERT ... SELECT

Можно вставить в таблицу сразу много строк, взяв их из результата `SELECT`:

```sql
INSERT INTO таблица (столбцы)
SELECT ... FROM ... WHERE ...;
```

Каждая найденная строка становится новой строкой. Так удобно «размножить» вставку по нескольким людям: выбираем из `person` нужных людей, а рядом считаем остальные значения.

Новые `id` должны быть разными и не пересекаться с существующими. Приём: взять `MAX(id)` из таблицы и прибавить к нему что-то уникальное для каждой строки, например `person.id`.

Ключевые слова для примеров: `INSERT`, `MAX`, `RETURNING`.
