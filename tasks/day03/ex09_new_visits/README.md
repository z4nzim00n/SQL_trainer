# Задание 09. Новая пицца: новые визиты

**Разрешено:** ANSI SQL

**Запрещено:** прямые числовые значения для идентификатора первичного ключа, людей и пиццерии

Зафиксируй новые посещения пиццерии `Dominos` людьми по имени `Denis` и `Irina` на дату **24 февраля 2022 года**. Идентификаторы людей и пиццерии получай запросами, `id` посещений вычисляй динамически.

> Задание изменяет данные (в тренажёре они откатываются). Проверяются люди, пиццерия и дата добавленных строк.
