# Задание 13. DELETE и внешние ключи

`DELETE FROM таблица WHERE условие` удаляет строки, подходящие под условие. **Без `WHERE` удалятся все строки.**

В `person_order` есть внешний ключ на `menu`: заказ ссылается на позицию меню. Пока такие заказы существуют, удалить строку из `menu` нельзя: база вернёт ошибку нарушения внешнего ключа. Поэтому сначала удаляем зависимые строки (заказы), потом саму пиццу.

Первый запрос: `DELETE FROM person_order WHERE order_date = '2022-02-25'`. Второй: `DELETE FROM menu WHERE pizza_name = 'greek pizza'`. Оба пишутся в редакторе подряд, через точку с запятой.

Ключевые слова для примеров: `DELETE`, `RETURNING`.
