# Задание 13. Вернём деньги клиентам

**Разрешено:** ANSI SQL

Напиши **два** DML-запроса (`DELETE`), которые:

1. удалят все новые заказы из задания 12 по дате заказа (25 февраля 2022 года);
2. затем удалят пиццу `greek pizza` из меню.

Порядок важен: пока на пиццу есть заказы, удалить её из меню нельзя.

> Задание изменяет данные (в тренажёре они откатываются).
