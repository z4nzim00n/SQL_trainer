# Задание 08. Новая пицца: динамически

**Разрешено:** ANSI SQL

**Запрещено:** прямые числовые значения для идентификатора первичного ключа и для пиццерии

Добавь в меню пиццу `sicilian pizza` по цене **900** рублей в пиццерию `Dominos`. Идентификатор новой строки вычисли как «максимальный существующий `id` + 1». Идентификатор пиццерии получи подзапросом по названию.

> Задание изменяет данные (в тренажёре они откатываются). Для проверки на скрытых данных число для `id` вписывать нельзя: оно будет другим.
