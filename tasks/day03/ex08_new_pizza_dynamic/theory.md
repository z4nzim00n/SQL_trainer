# Задание 08. INSERT со значениями из подзапросов

Значением в `VALUES` может быть не только константа, но и подзапрос в скобках, который возвращает одно значение:

```sql
VALUES ((SELECT MAX(id) FROM menu) + 1, (SELECT id FROM pizzeria WHERE name = 'Dominos'), ...)
```

`MAX(id)` возвращает наибольший `id` в таблице, прибавив 1, получаем свободный номер. Подзапрос по названию находит `id` пиццерии, так что вписывать число не нужно, и запрос работает на любых данных.

Порядок выполнения: сначала считаются подзапросы, затем строка вставляется.

Ключевые слова для примеров: `INSERT`, `MAX`, `RETURNING`.
