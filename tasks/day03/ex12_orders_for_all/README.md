# Задание 12. Новые заказы для всех

**Разрешено:** ANSI SQL, `generate_series(...)`

**Запрещено:** прямые числовые значения для идентификатора первичного ключа и пиццерии; оконные функции (`ROW_NUMBER()`, `OVER`); отдельные операторы `INSERT` на каждую строку (`VALUES`)

Шаблон: «insert-select» (`INSERT INTO ... SELECT ...`).

Зарегистрируй заказы `greek pizza` для **всех клиентов** на **25 февраля 2022 года**. Идентификатор меню получи подзапросом, `id` заказов вычисли динамически.

> Задание изменяет данные (в тренажёре они откатываются).
