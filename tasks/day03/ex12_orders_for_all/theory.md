# Задание 12. INSERT ... SELECT для всех строк

Нужна одна строка заказа на **каждого** человека, поэтому источником данных служит сама таблица `person`: `INSERT INTO person_order ... SELECT ... FROM person` создаст по строке на каждого.

Для каждой строки нужно посчитать:

- `id` заказа: наибольший существующий `id` плюс число, уникальное для строки (подойдёт `person.id`; запрет оконных функций исключает `ROW_NUMBER()`);
- `person_id`: это `person.id`;
- `menu_id`: подзапрос по названию `greek pizza`;
- дату: константа `'2022-02-25'`.

Замечание: `generate_series(1, N)` тоже выдаёт числа для `id`, но связать их с людьми сложнее. Здесь достаточно `person.id`.

Ключевые слова для примеров: `INSERT`, `MAX`, `GENERATE_SERIES`.
