# Задание 03. Мультимножества: EXCEPT ALL и UNION ALL

Для каждой пиццерии есть два списка посещений: женщин и мужчин. Название пиццерии в списке повторяется столько раз, сколько было посещений. Это **мультимножество**.

- `женщины EXCEPT ALL мужчины` оставляет названия, которых у женщин **больше**, причём ровно на разницу посещений;
- `мужчины EXCEPT ALL женщины` делает то же в обратную сторону;
- `UNION ALL` складывает два результата, сохраняя повторы.

Каждую часть нужно взять в скобки, а один общий `ORDER BY` написать в самом конце. Заметь: обычный `EXCEPT` без `ALL` убрал бы повторы и показал лишь сам факт различия, а не его величину.

Названия берутся через цепочку `person_visits → person → pizzeria`: пол в `person`, название пиццерии в `pizzeria`.

Ключевые слова для примеров: `EXCEPT ALL`, `UNION ALL`, `JOIN`, `ORDER BY`.
