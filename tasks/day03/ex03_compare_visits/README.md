# Задание 03. Сравним посещения

**Разрешено:** ANSI SQL

Найди пиццерии, которые чаще посещали **женщины** или чаще посещали **мужчины**: то есть те пиццерии, у которых число посещений женщин и мужчин различается. Одна и та же пиццерия выводится столько раз, на сколько посещений одни посетители её посещали чаще других.

Сохраняй дубликаты при использовании операторов работы с множествами (`UNION ALL`, `EXCEPT ALL`, `INTERSECT ALL`).

Результат отсортируй по названию пиццерии. Столбец результата: `pizzeria_name`.
