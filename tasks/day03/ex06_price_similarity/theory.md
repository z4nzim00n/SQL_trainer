# Задание 06. Соединение таблицы с самой собой

Чтобы сравнить строки одной таблицы между собой, её берут в запрос **дважды** под разными псевдонимами: `menu AS m1 JOIN menu AS m2`. Теперь `m1` и `m2` это две независимые «копии» таблицы.

Условие `ON` собирает пары: одинаковое название (`m1.pizza_name = m2.pizza_name`), одинаковая цена и **разные** пиццерии. Если написать `m1.pizzeria_id <> m2.pizzeria_id`, каждая пара получится дважды (A,B и B,A). Условие `m1.pizzeria_id > m2.pizzeria_id` оставляет только одно направление и сразу исключает пару «пиццерия сама с собой».

Названия пиццерий берутся ещё двумя `JOIN` к `pizzeria` (тоже под разными псевдонимами).

Ключевые слова для примеров: `JOIN`, `AS`, `ON`, `ORDER BY`.
