# Задание 06. Пиццы с одинаковой ценой

**Разрешено:** ANSI SQL

Найди пиццы с одинаковым названием и одинаковой ценой, но из **разных** пиццерий. Каждую пару выводи один раз (без зеркального дубля). В первом столбце названия пиццерии идёт пиццерия с **большим** идентификатором.

Результат отсортируй по названию пиццы. Имена столбцов: `pizza_name`, `pizzeria_name_1`, `pizzeria_name_2`, `price`.

| pizza_name | pizzeria_name_1 | pizzeria_name_2 | price |
| --- | --- | --- | --- |
| cheese pizza | Best Pizza | Papa Johns | 700 |
| … | … | … | … |
