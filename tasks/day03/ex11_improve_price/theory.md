# Задание 11. UPDATE

`UPDATE таблица SET столбец = новое_значение WHERE условие` меняет существующие строки. Новое значение можно вычислять из старого: `price = price * 0.9` (было 800, станет 720).

**`WHERE` обязателен:** без него изменятся **все** строки таблицы. Условие должно выбрать только нужную пиццу: `WHERE pizza_name = 'greek pizza'`.

Скидка 10% это умножение на 0.9. Запись `price - price * 0.1` даёт то же.

Ключевые слова для примеров: `UPDATE`, `RETURNING`.
