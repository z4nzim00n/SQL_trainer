# Задание 04. Любимые пиццы

**Разрешено:** ANSI SQL

Найди полную информацию обо всех вариантах пиццерий и цен на пиццу с грибами (`mushroom pizza`) или пепперони (`pepperoni pizza`).

Отсортируй результат по названию пиццы и названию пиццерии. Используй названия столбцов из примера.

| pizza_name | pizzeria_name | price |
| --- | --- | --- |
| mushroom pizza | Dominos | 1100 |
| mushroom pizza | Papa Johns | 950 |
| pepperoni pizza | Best Pizza | 800 |
| ... | ... | ... |
