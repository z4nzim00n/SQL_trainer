# Задание 02. FULL JOIN и COALESCE

`FULL JOIN` сохраняет **все** строки обеих таблиц: если пары нет, подставляется `NULL` с той стороны, где пара не нашлась. Так в одном результате оказываются и люди без посещений, и пиццерии без посетителей.

Посещения нужно ограничить датами 1–3 января. Если поставить условие в `WHERE` после соединения, оно удалит строки с `NULL`. Поэтому сначала отбирают нужные посещения **подзапросом** и уже его соединяют с `person` и `pizzeria` (оба соединения `FULL JOIN`).

`COALESCE(значение, запасное)` возвращает первое значение, которое не `NULL`. Так `NULL` в имени превращается в `'-'`.

Сортировка по нескольким столбцам перечисляется через запятую. `NULL` при сортировке по возрастанию идёт в конец.

## Примеры на маленьких таблицах

Все студенты и все курсы, пары там, где они есть:

```sql-run
SELECT COALESCE(students.name, '-') AS student, COALESCE(courses.title, '-') AS course
FROM students
FULL JOIN courses ON students.course_id = courses.id
ORDER BY student, course;
```

`COALESCE` сам по себе:

```sql-run
SELECT name, COALESCE(city, '-') AS city
FROM students
ORDER BY name;
```
