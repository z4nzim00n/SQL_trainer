# Задание 10. Люди из одного города

**Разрешено:** ANSI SQL

Найди имена людей, проживающих по одному адресу (в одном городе). Каждая пара должна встретиться **один раз** (без зеркальных дублей «A и B» / «B и A») и без пар «человек с самим собой».

Результат отсортируй по трём столбцам: имя первого человека, имя второго человека, общий адрес. Используй названия столбцов `person_name1`, `person_name2`, `common_address`.

Для пары берётся такой порядок: у первого человека `id` **больше**, чем у второго.

| person_name1 | person_name2 | common_address |
| --- | --- | --- |
| Andrey | Anna | Moscow |
| Denis | Kate | Kazan |
| Elvira | Denis | Kazan |
| ... | ... | ... |
