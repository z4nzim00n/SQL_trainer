# Задание 05. Фильтр по двум условиям

Повторяем основы: два условия через `AND`, одно из них сравнение с числом. «Старше 25» значит строго больше: `age > 25`, поэтому женщины ровно 25 лет не попадут в результат.

Текстовые значения пишутся в одинарных кавычках: `'female'`.

## Примеры на маленьких таблицах

```sql-run
SELECT name
FROM students
WHERE city = 'Berlin' AND age > 19
ORDER BY name;
```
