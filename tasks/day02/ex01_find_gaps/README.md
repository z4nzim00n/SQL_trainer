# Задание 01. Найти пропуски

**Разрешено:** `generate_series(...)`

**Запрещено:** `NOT IN`, `IN`, `NOT EXISTS`, `EXISTS`, `UNION`, `EXCEPT`, `INTERSECT`

Напиши запрос, который возвращает **отсутствующие даты** с 1 по 10 января 2022 года (включительно) для посещений людьми с идентификаторами 1 и 2: то есть дни, **пропущенные обоими**.

Отсортируй результат по дате по возрастанию. Столбец результата называется `missing_date`.

| missing_date |
| --- |
| 2022-01-03 |
| 2022-01-04 |
| 2022-01-05 |
| ... |
