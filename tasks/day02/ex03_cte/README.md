# Задание 03. Переписать на CTE

**Разрешено:** `generate_series(...)`

**Запрещено:** `NOT IN`, `IN`, `NOT EXISTS`, `EXISTS`, `UNION`, `EXCEPT`, `INTERSECT`

Вернись к заданию 01 и перепиши запрос с использованием **CTE** (Common Table Expression, `WITH`). В блоке CTE реализуй генератор дат. Результат должен совпадать с результатом задания 01 (столбец `missing_date`).
