# Задание 00. Двигайся влево, двигайся вправо

**Разрешено:** ANSI SQL

**Запрещено:** `NOT IN`, `IN`, `NOT EXISTS`, `EXISTS`, `UNION`, `EXCEPT`, `INTERSECT`

Напиши запрос, который выведет список пиццерий с их рейтингом, но только тех, которые **никто не посещал**. Столбцы результата: `name`, `rating`.
