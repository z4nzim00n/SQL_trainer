# Общая сборка: две оценки в долларах рядом

Роли выполнены. Теперь соберите итоговый скрипт: он сравнивает оценку по **последнему** курсу (Роль 1) и по курсу **на момент операции** (Роль 2).

**Задание.** Напишите единый скрипт, который по порядку:

1. выполняет два `INSERT` в `currency` из карточки Роли 2 (EUR: `0.85` на `2022-01-01 13:29` и `0.79` на `2022-01-08 13:29`);
2. создаёт представление `v_total_volume` из запроса Роли 1 (задание 00 проекта, без `ORDER BY`);
3. создаёт представление `v_balance_usd` из запроса Роли 2 (задание 01 проекта, без `ORDER BY`);
4. завершается запросом-сверкой.

**Сверка.** Для каждого сочетания `name`, `lastname`, `currency_name`, которое есть **в обоих** представлениях, верни:

- `usd_last_rate`: сумма `total_volume_in_usd` из `v_total_volume`;
- `usd_op_rate`: сумма `currency_in_usd` из `v_balance_usd`;
- `diff`: `usd_last_rate - usd_op_rate`.

Сначала сгруппируйте каждое представление по `name`, `lastname`, `currency_name`, затем соедините.

Отсортируй по `name` по убыванию, затем по `lastname` и `currency_name`.

Столбцы: `name`, `lastname`, `currency_name`, `usd_last_rate`, `usd_op_rate`, `diff`.

Строки с валютой `'not defined'` в сверку не попадают: в `v_balance_usd` их нет.
