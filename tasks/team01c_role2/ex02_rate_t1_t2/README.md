# Задание 02. Курс из будущего (t2)

**Разрешено:** SQL

Расширь предыдущий запрос (те же два `INSERT` уже выполнены).

Для каждой операции с известной валютой верни:

- `rate_t1`: ближайший курс в прошлом (`updated <= balance.updated`), иначе `NULL`;
- `rate_t2`: ближайший курс в **будущем** (`updated > balance.updated`, самый ранний из таких), иначе `NULL`;
- `rate_used`: итоговый курс: `rate_t1`, а если его нет, то `rate_t2`.

Столбцы: `user_id`, `currency_id`, `updated`, `rate_t1`, `rate_t2`, `rate_used`.

Отсортируй по `user_id`, `updated`, `currency_id`.

| user_id | currency_id | updated | rate_t1 | rate_t2 | rate_used |

| 101 | 100 | 2022-01-09 04:23:00 | 0.7900 | 0.8700 | 0.7900 |
