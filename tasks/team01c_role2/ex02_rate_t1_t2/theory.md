# Теория: два кандидата и выбор

Второй курс ищется зеркально первому:

```sql
(SELECT c.rate_to_usd
 FROM currency c
 WHERE c.id = b.currency_id AND c.updated > b.updated
 ORDER BY c.updated ASC
 LIMIT 1) AS rate_t2
```

Теперь `ASC`, потому что нужен **ближайший** по времени, то есть самый ранний из будущих.

Чтобы не повторять подзапросы в итоговом столбце, выберите оба в `WITH`, а во внешнем запросе возьмите `COALESCE(rate_t1, rate_t2)`.

Важно: t1 сначала. По правилу курс из будущего нужен только тогда, когда курса из прошлого нет, даже если будущий ближе по времени.

Ключевые слова для примеров: `WITH`, `COALESCE`, `LIMIT`.
