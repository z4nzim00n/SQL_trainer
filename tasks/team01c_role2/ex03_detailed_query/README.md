# Задание 03. Detailed Query

**Разрешено:** ANSI SQL

Это задание 01 проекта. Два `INSERT` из карточки уже выполнены.

Верни все операции по балансу (**валюты, которых нет в `currency`, игнорируем**) с названием валюты и суммой в долларах, пересчитанной по курсу на момент операции.

| Поле | Формула |
| --- | --- |
| `name` | `user.name`; если `NULL` (или пользователя нет), то `'not defined'` |
| `lastname` | `user.lastname`; если `NULL` (или пользователя нет), то `'not defined'` |
| `currency_name` | `currency.name` |
| `currency_in_usd` | `balance.money` умножить на курс |

Курс выбирается так:

1. найди ближайший курс валюты **в прошлом** (t1): `currency.updated <= balance.updated`;
2. если t1 нет, найди ближайший курс **в будущем** (t2): `currency.updated > balance.updated`;
3. используй курс t1 **ИЛИ** t2.

Одна строка соответствует одной операции. Операции пользователя, которого нет в `"user"`, тоже выводим (имя и фамилия `'not defined'`).

Отсортируй по `name` **по убыванию**, затем по `lastname`, `currency_name` и `currency_in_usd` **по возрастанию**.

| name | lastname | currency_name | currency_in_usd |
| --- | --- | --- | --- |
| Сергей | Смирнов | EUR | 13.350000 |
| … | … | … | … |
