# Задание 01. Курс из прошлого (t1)

**Разрешено:** SQL

Перед запросом выполнены два `INSERT` из карточки роли.

Для каждой операции из `balance`, у которой валюта есть в `currency`, найди **ближайший курс в прошлом**: самый свежий `rate_to_usd` с `updated` не позже `balance.updated`. Если такого нет, в `rate_t1` должен быть `NULL`.

Столбцы: `user_id`, `currency_id`, `money`, `updated`, `rate_t1`.

Операции с валютой, которой нет в `currency`, в результат **не попадают**.

Отсортируй по `user_id`, `updated`, `currency_id`, `money`.

| user_id | currency_id | money | updated | rate_t1 |
| --- | --- | --- | --- | --- |
| 101 | 101 | 40.00 | 2022-01-05 10:00:00 | 1.0000 |
| 101 | 100 | 100.00 | 2022-01-09 04:23:00 | 0.7900 |
| … | … | … | … | … |
