# Роль 2 · «Инженер курсов»: твоя карточка

Ты отвечаешь за **курс на момент операции**. Курс валюты менялся, и деньги, потраченные в январе, надо пересчитывать по январскому курсу, а не по последнему. Напарник (Роль 1) считает по последнему курсу.

## Твои задания

1. **ex01. Курс из прошлого (t1)**: для каждой операции найди ближайший курс **до** операции.
2. **ex02. Курс из будущего (t2)**: добавь ближайший курс **после** и выбери итоговый.
3. **ex03. Detailed Query**: итоговый запрос (задание 01 проекта).

## Особенность данных

Перед заданиями проекта выполняются два `INSERT` (они уже сделаны в тренажёре за тебя, в настоящем проекте их нужно выполнить самому):

```sql
INSERT INTO currency VALUES (100, 'EUR', 0.85, '2022-01-01 13:29');
INSERT INTO currency VALUES (100, 'EUR', 0.79, '2022-01-08 13:29');
```

Они добавляют в историю евро два старых курса.

## Что отдать напарнику

Запрос из ex03, оформленный как представление `v_balance_usd` (для общей сборки).

## Что получить от напарника

Представление `v_total_volume` (его задание 00 проекта).
