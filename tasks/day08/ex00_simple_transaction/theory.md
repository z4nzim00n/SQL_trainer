# Задание 00. Транзакция и видимость изменений

**Транзакция** это группа команд, которая выполняется как единое целое: либо применяются все, либо ни одной. Границы задают команды:

- `BEGIN`: начать транзакцию;
- `COMMIT`: зафиксировать (применить) все изменения;
- `ROLLBACK`: отменить все изменения с начала транзакции.

Пока транзакция не зафиксирована, её изменения видны **только ей самой**. Другие сессии продолжают видеть прежние данные. Именно это и нужно показать: `UPDATE` внутри `BEGIN` ещё не «опубликован».

Это свойство называется **изоляцией** (буква I в ACID). Остальные буквы: атомарность (всё или ничего), согласованность (данные не нарушают правила), долговечность (после `COMMIT` данные не пропадут).

Как работать с двумя сессиями: открой два терминала с `psql`. Команды вводи в строгом порядке из таблицы шагов, переключаясь между окнами.

Ключевые слова для примеров: `BEGIN`, `COMMIT`, `ROLLBACK`, `TRANSACTION`, `UPDATE`.
