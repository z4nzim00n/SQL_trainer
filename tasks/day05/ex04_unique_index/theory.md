# Задание 04. UNIQUE-индекс

Уникальный индекс не просто ускоряет поиск, но и **запрещает дубликаты** по своим столбцам:

```sql
CREATE UNIQUE INDEX имя ON таблица (a, b);
```

Для составного индекса уникальна **комбинация** значений: пара `(pizzeria_id, pizza_name)` не может повторяться, а отдельно `pizzeria_id` или `pizza_name` повторяться могут. В нашем меню это значит: одна и та же пицца в одной и той же пиццерии не может быть записана дважды, а в разных пиццериях может.

Если в таблице уже есть дубликаты, создать такой индекс не получится (будет ошибка).

Уникальность можно описать и ограничением (`UNIQUE (a, b)` в `CREATE TABLE` или `ALTER TABLE`): внутри PostgreSQL ограничение тоже создаёт уникальный индекс.

Ключевые слова для примеров: `UNIQUE`, `CREATE INDEX`, `INDEX`.
