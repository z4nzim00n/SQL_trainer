# Задание 01. Как увидеть, что индекс работает?

**Разрешено:** ANSI SQL

Индексы из задания 00 уже созданы. Напиши запрос, который возвращает названия пицц и названия соответствующих пиццерий (сортировка не нужна):

| pizza_name | pizzeria_name |
| --- | --- |
| cheese pizza | Pizza Hut |
| … | … |

Нужно **доказать**, что индекс на внешнем ключе при этом используется. Доказательство это вывод `EXPLAIN ANALYZE` для твоего запроса, в котором есть строка вида:

```
->  Index Scan using idx_menu_pizzeria_id on menu m  (...)
```

**Подсказка:** подумай, почему индексы могут не использоваться сами по себе и что нужно сделать, чтобы их задействовать.

> Тренажёр сам смотрит план запроса и проверяет, что в нём есть `idx_menu_pizzeria_id`. Напиши в редакторе всё, что нужно для этого (настройку и `EXPLAIN ANALYZE` с запросом).
