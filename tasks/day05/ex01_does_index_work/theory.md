# Задание 01. EXPLAIN и выбор плана

`EXPLAIN запрос` показывает **план**: как PostgreSQL собирается выполнять запрос. `EXPLAIN ANALYZE запрос` дополнительно **выполняет** его и добавляет реальное время.

В плане интересны строки вида:

- `Seq Scan on таблица`: таблица читается целиком, индекс не используется;
- `Index Scan using имя_индекса`: поиск через индекс, затем чтение строк;
- `Index Only Scan`: все нужные данные взяты прямо из индекса, в таблицу не заглядываем.

**Почему индекс может не использоваться.** Планировщик считает стоимость каждого варианта. Если таблица крошечная (у нас всего несколько десятков строк), прочитать её целиком дешевле, чем идти по индексу. Поэтому на учебных данных индекс «не работает».

Чтобы увидеть, что индекс вообще годится, можно запретить планировщику последовательное чтение:

```sql
SET enable_seqscan = off;
```

Это только для учебных экспериментов, в рабочих базах так не делают. Настройка действует до конца сеанса (в тренажёре до конца запроса).

Ключевые слова для примеров: `EXPLAIN`, `EXPLAIN ANALYZE`, `JOIN`.
