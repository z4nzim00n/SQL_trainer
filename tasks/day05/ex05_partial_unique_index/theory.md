# Задание 05. Частичный индекс

У индекса может быть условие `WHERE`: тогда в него попадают **только строки, подходящие под условие**.

```sql
CREATE UNIQUE INDEX имя ON таблица (a, b) WHERE условие;
```

Плюсы: индекс меньше и быстрее, а уникальность (если индекс `UNIQUE`) проверяется только среди отобранных строк. Здесь пара `(person_id, menu_id)` не должна повторяться среди заказов за 1 января 2022, а в остальные даты один и тот же человек может заказывать одну позицию меню сколько угодно раз.

Чтобы запрос воспользовался частичным индексом, его условие должно **включать** условие индекса: `WHERE order_date = '2022-01-01'`. Столбец `order_date` в индекс класть не нужно: он известен (одинаков для всех строк индекса), поэтому запрос, выбирающий только `person_id` и `menu_id`, выполняется как `Index Only Scan`.

Ключевые слова для примеров: `UNIQUE`, `CREATE INDEX`, `WHERE`.
