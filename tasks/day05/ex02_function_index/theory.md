# Задание 02. Индекс по выражению

Обычный индекс по `name` бесполезен для запроса `WHERE UPPER(name) = 'ANNA'`: база ищет не по самому значению `name`, а по результату функции над ним. Нужен индекс, построенный по этому же выражению:

```sql
CREATE INDEX idx_person_name ON person (UPPER(name));
```

Теперь в индексе лежат уже имена в верхнем регистре, и условие `UPPER(name) = '...'` может им воспользоваться. Выражение в запросе должно **совпадать** с выражением в индексе: `LOWER(name)` или `name` без функции индекс не задействуют.

Применение: поиск без учёта регистра, по году из даты, по части строки. Функция в индексе должна быть «неизменяемой» (давать один результат для одних входных данных).

Ключевые слова для примеров: `CREATE INDEX`, `UPPER`, `EXPLAIN`.
