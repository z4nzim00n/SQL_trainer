# Задание 02. Формула в индексе

**Разрешено:** ANSI SQL

Создай **функциональный** B-Tree индекс с именем `idx_person_name` по столбцу `name` таблицы `person`. Индекс должен содержать имена людей **в верхнем регистре**.

Напиши запрос, который доказывает (через `EXPLAIN ANALYZE`), что индекс `idx_person_name` используется.

> Тренажёр сам проверяет план запроса `SELECT * FROM person WHERE UPPER(name) = 'ANNA'` на таблице после твоего индекса (последовательное чтение при проверке отключено, как в задании 01). Свой запрос для доказательства напиши в редакторе тоже.
