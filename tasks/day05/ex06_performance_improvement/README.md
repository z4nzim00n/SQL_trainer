# Задание 06. Ускорим запрос

**Разрешено:** ANSI SQL

Проанализируй запрос с технической точки зрения (логику не обсуждаем):

```sql
SELECT
    m.pizza_name AS pizza_name,
    max(rating) OVER (PARTITION BY rating ORDER BY rating
        ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING) AS k
FROM menu m
INNER JOIN pizzeria pz ON m.pizzeria_id = pz.id
ORDER BY 1, 2;
```

Создай новый B-Tree индекс с именем `idx_1`, который **улучшит план** этого запроса. Докажи улучшение с помощью `EXPLAIN ANALYZE`.

**Подсказка:** это похоже на «метод грубой силы» для поиска хорошего покрывающего индекса: пробуй разные наборы столбцов, а перед каждой новой попыткой удаляй `idx_1` (`DROP INDEX idx_1`).

> Тренажёр отключает последовательное сканирование (на такой маленькой таблице иначе индекс не нужен), смотрит план и проверяет, что `idx_1` используется и что стоимость плана с ним **ниже**, чем без него.
