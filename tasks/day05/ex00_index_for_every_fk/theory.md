# Задание 00. Индексы и внешние ключи

**Индекс** это отдельная структура, которая помогает быстро находить строки по значению столбца. Без индекса база читает таблицу целиком («последовательное сканирование»), с индексом может сразу перейти к нужным строкам. Самый обычный тип: **B-Tree** (сбалансированное дерево), он создаётся по умолчанию.

```sql
CREATE INDEX имя_индекса ON таблица (столбец);
```

Важное про внешние ключи: PostgreSQL **сам не создаёт индексы** на столбцы с внешним ключом (в отличие от первичного ключа, где индекс есть всегда). А именно по этим столбцам мы постоянно делаем `JOIN`, поэтому индекс на них обычно нужен.

Цена индексов: они занимают место и замедляют `INSERT`, `UPDATE` и `DELETE`, потому что вместе с таблицей надо обновлять и индекс. Индексы не меняют результат запроса, только скорость.

Ключевые слова для примеров: `CREATE INDEX`, `INDEX`, `FOREIGN KEY`.
