# Задание 00. CREATE TABLE с ограничениями

```sql
CREATE TABLE имя (
    столбец тип [ограничения],
    ...
    CONSTRAINT имя_ограничения FOREIGN KEY (столбец) REFERENCES другая_таблица (столбец)
);
```

- **`PRIMARY KEY`**: уникальный идентификатор строки (значения не повторяются и не бывают `NULL`);
- **`FOREIGN KEY ... REFERENCES`**: значение столбца обязано существовать в родительской таблице (нельзя поставить скидку несуществующему клиенту);
- **`CONSTRAINT имя`** перед ограничением задаёт ему имя. Без него PostgreSQL придумает имя сам, а по явному имени ограничение удобно потом найти или удалить.

Тип столбца внешнего ключа должен совпадать с типом столбца, на который он ссылается: у нас `id` это `bigint`, поэтому и `person_id`, `pizzeria_id` делаем `bigint`.

Скидка в процентах может быть дробной (10.5), поэтому тип `numeric`, а не `integer`.

Ключевые слова для примеров: `CREATE TABLE`, `PRIMARY KEY`, `FOREIGN KEY`, `REFERENCES`.
