# Задание 00. Скидки, скидки: их любят все

**Разрешено:** SQL, DML, DDL

Нужно добавить в модель данных новую бизнес-возможность: **персональные скидки** клиентов в конкретных пиццериях. Создай таблицу связи `person_discounts` по правилам:

1. атрибут `id` это первичный ключ (выбери тот же тип данных, что у столбцов `id` в существующих таблицах);
2. атрибуты `person_id` и `pizzeria_id` это внешние ключи на соответствующие таблицы (типы должны совпадать с типами `id` родительских таблиц);
3. явные имена ограничений внешних ключей по шаблону `fk_{имя_таблицы}_{имя_столбца}`, например `fk_person_discounts_person_id`;
4. атрибут `discount` хранит скидку в процентах. Значение может быть дробным, поэтому используй тип `numeric`.

> Тренажёр проверяет получившуюся структуру: столбцы с типами, первичный и внешние ключи и их имена.
