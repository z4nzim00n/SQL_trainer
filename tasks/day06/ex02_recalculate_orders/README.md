# Задание 02. Пересчитаем историю заказов

**Разрешено:** SQL, DML, DDL

Напиши запрос, который возвращает список заказов с **фактической стоимостью** и **стоимостью с учётом скидки** клиента в соответствующей пиццерии. Отсортируй результат по имени клиента и названию пиццы.

Скидка берётся из `person_discounts` для пары «клиент и пиццерия заказа». Столбец `discount_price` округли до целого числа.

| name | pizza_name | price | discount_price | pizzeria_name |
| --- | --- | --- | --- | --- |
| Andrey | cheese pizza | 800 | 624 | Dominos |
| Andrey | mushroom pizza | 1100 | 858 | Dominos |
| … | … | … | … | … |
