# Задание 01. INSERT ... SELECT с группировкой и CASE

Три приёма в одном запросе.

**Группировка.** `GROUP BY person_id, pizzeria_id` превращает все заказы одного клиента в одной пиццерии в одну строку, а `COUNT(*)` считает, сколько заказов было. В `person_order` пиццерии нет, её даёт `menu.pizzeria_id`, поэтому нужен `JOIN menu`.

**Условие `CASE`.** Выбор значения по правилам:

```sql
CASE WHEN COUNT(*) = 1 THEN 10.5
     WHEN COUNT(*) = 2 THEN 22
     ELSE 30 END
```

Ветки проверяются сверху вниз, срабатывает первая подошедшая; `ELSE` берёт всё остальное. Агрегат `COUNT(*)` внутри `CASE` допустим, потому что `CASE` вычисляется для каждой группы.

**Номер строки.** `ROW_NUMBER() OVER ()` пронумерует результирующие строки 1, 2, 3, … Это удобный способ получить уникальные `id`.

Результат `SELECT` вставляется в таблицу командой `INSERT INTO таблица (столбцы) SELECT ...`.

Ключевые слова для примеров: `CASE`, `ROW_NUMBER`, `OVER`, `GROUP BY`, `INSERT`, `JOIN`.
