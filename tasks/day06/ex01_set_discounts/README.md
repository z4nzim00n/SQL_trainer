# Задание 01. Назначим персональные скидки

**Разрешено:** SQL, DML, DDL

Структура для скидок есть, нужно заполнить таблицу `person_discounts`. Напиши DML-оператор `INSERT INTO ... SELECT ...`, который на основе истории заказов `person_order` создаст новые записи по правилам:

1. сгруппируй данные по `person_id` и `pizzeria_id` (пиццерию заказа даёт меню);
2. рассчитай скидку по псевдокоду:
   - если количество заказов равно 1, то скидка **10.5**;
   - иначе если количество заказов равно 2, то скидка **22**;
   - иначе скидка **30**;
3. для первичного ключа используй конструкцию `ROW_NUMBER() OVER () AS id`.
