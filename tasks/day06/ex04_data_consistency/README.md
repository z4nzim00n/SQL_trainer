# Задание 04. Больше согласованности

**Разрешено:** SQL, DML, DDL

Добавь для существующих столбцов таблицы `person_discounts` правила:

1. `person_id` не должен содержать `NULL` (имя ограничения `ch_nn_person_id`);
2. `pizzeria_id` не должен содержать `NULL` (имя `ch_nn_pizzeria_id`);
3. `discount` не должен содержать `NULL` (имя `ch_nn_discount`);
4. `discount` по умолчанию равен `0` (0%);
5. `discount` лежит в диапазоне от 0 до 100 (имя `ch_range_discount`).

> Таблица к началу задания создана и заполнена. Тренажёр проверяет имена и условия ограничений и значение по умолчанию.
