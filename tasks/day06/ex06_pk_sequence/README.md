# Задание 06. Автоматическая генерация первичного ключа

**Разрешено:** SQL, DML, DDL

**Запрещено:** жёстко заданные (hard-coded) значения количества строк для установки значения последовательности

Создай последовательность `seq_person_discounts` (начинается с 1) и сделай так, чтобы значение по умолчанию для атрибута `id` таблицы `person_discounts` автоматически брало следующее значение из этой последовательности при каждой вставке.

Обрати внимание: следующее значение последовательности должно быть равно **количеству строк в таблице плюс 1**. Установи актуальное значение последовательности по этой формуле; иначе при вставке получишь нарушение первичного ключа.

> Таблица заполнена и уже содержит ограничения из задания 04. После твоих запросов тренажёр сам вставит новую строку, не указывая `id`, и проверит, какой `id` она получила.
