# Задание 05. COMMENT ON

Комментарий это описание объекта базы, которое хранится вместе с ним. Его видят клиенты вроде DataGrip, генераторы документации, коллеги.

```sql
COMMENT ON TABLE таблица IS 'описание';
COMMENT ON COLUMN таблица.столбец IS 'описание';
```

Хороший комментарий отвечает не «что это за тип», а «зачем это нужно бизнесу»: что означает значение, в каких единицах, откуда берётся. Например, для `discount`: размер скидки в процентах, от 0 до 100.

Прочитать комментарий можно функциями `obj_description` (для таблицы) и `col_description` (для столбца). Удалить комментарий можно, назначив `IS NULL`.

Ключевые слова для примеров: `COMMENT`.
