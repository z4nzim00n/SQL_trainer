# Задание 05. Правила управления данными

**Разрешено:** SQL, DML, DDL

По политике управления данными (Data Governance) таблицы и столбцы должны быть описаны. Добавь комментарии к таблице `person_discounts` и ко **всем её столбцам**: на английском или русском (на твой выбор), объясняющие бизнес-назначение таблицы и каждого атрибута.

> Тренажёр проверяет, что есть непустой комментарий у таблицы и у каждого из четырёх столбцов (текст может быть любым).
