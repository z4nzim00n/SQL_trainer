# Задание 03. Улучшения на пути

**Разрешено:** SQL, DML, DDL

Нужно одновременно улучшить согласованность данных и производительность. Создай **уникальный многоколоночный индекс** с именем `idx_person_discounts_unique`, который не даст продублировать пару `person_id` и `pizzeria_id` (в этом порядке).

После создания индекса напиши любое простое SQL-выражение, которое демонстрирует использование индекса через `EXPLAIN ANALYZE`. Пример подтверждения:

```
Index Scan using idx_person_discounts_unique on person_discounts
```

> Тренажёр проверяет индекс (уникальный, столбцы, порядок) и план запроса `SELECT * FROM person_discounts WHERE person_id = 1 AND pizzeria_id = 1`. При проверке последовательное чтение отключено (см. Day 05).
