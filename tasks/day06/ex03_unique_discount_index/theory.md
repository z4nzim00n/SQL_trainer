# Задание 03. Уникальный индекс как защита от дублей

Скидка должна быть **одна** для пары клиент и пиццерия. Если не защитить таблицу, в неё можно по ошибке вставить две разные скидки для одной пары, и результат запроса из задания 02 удвоит строки.

Уникальный индекс решает сразу две задачи:

- **согласованность:** попытка вставить вторую строку с той же парой завершится ошибкой;
- **скорость:** поиск скидки по паре идёт через индекс.

```sql
CREATE UNIQUE INDEX имя ON таблица (a, b);
```

Порядок столбцов `(person_id, pizzeria_id)` подходит и для поиска «все скидки клиента» (левая часть индекса), и для поиска конкретной пары.

Чтобы увидеть работу индекса в плане, используй `EXPLAIN ANALYZE` с условием на оба столбца (напомним, что на крошечной таблице планировщику может понадобиться `SET enable_seqscan = off`, в тренажёре проверка делает это сама).

Ключевые слова для примеров: `UNIQUE`, `CREATE INDEX`, `EXPLAIN ANALYZE`.
