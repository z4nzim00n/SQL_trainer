# Задание 02. Аномалии

**Разрешено:** SQL

Найди «осиротевшие» операции: в `balance` есть пользователь, которого нет в `"user"`, или валюта, которой нет в `currency`.

Верни **уникальные** сочетания `user_id`, `currency_id` и текст проблемы в столбце `problem`:

| Что случилось | `problem` |
| --- | --- |
| нет пользователя | `no user` |
| нет валюты | `no currency` |
| нет ни того, ни другого | `no user, no currency` |

Отсортируй по `user_id`, затем по `currency_id`.

| user_id | currency_id | problem |
| --- | --- | --- |
| 102 | 199 | no currency |
| 999 | 100 | no user |
| … | … | … |
