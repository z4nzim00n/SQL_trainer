# Теория: итог по хранилищу с аномалиями

Задача складывается из трёх знакомых кусков.

**1. Последний курс валюты.** Сделайте во временной таблице (`WITH`) одну строку на валюту: `DISTINCT ON` или `ROW_NUMBER`. Если соединить `balance` с полной `currency`, курсы размножат строки, и суммы удвоятся.

**2. Соединения, не теряющие данные.** Основа запроса: `balance`. К ней `LEFT JOIN "user"` и `LEFT JOIN` последнего курса. Тогда операции без пользователя или без валюты не пропадут.

**3. Группировка и подстановка значений.**

```sql
COALESCE(u.name, 'not defined') AS name
SUM(b.money) AS volume
COALESCE(c.rate_to_usd, 1) AS last_rate_to_usd
```

Группировать нужно по тому, что определяет строку: пользователь (`b.user_id`), тип, валюта (`b.currency_id`). Остальные столбцы (`u.name`, `c.name`, ...) добавляются в `GROUP BY` ради синтаксиса.

Группируйте по `user_id`, а не только по имени: у разных пользователей могут совпасть имена.

Порядок: `ORDER BY name DESC, lastname, type, currency_name`. Здесь `name` и `lastname` — это уже подставленные значения.

Ключевые слова для примеров: `WITH`, `LEFT JOIN`, `COALESCE`, `SUM`, `GROUP BY`.
