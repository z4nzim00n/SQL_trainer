# Роль 1 · «Аналитик хранилища»: твоя карточка

Ты отвечаешь за **итоговый объём средств** по пользователям. Напарник (Роль 2, «Инженер курсов») считает суммы по курсу на момент каждой операции. Вы вместе получите две разные оценки в долларах и сверите их.

## Твои задания

1. **ex01. Последний курс**: для каждой валюты найди самый свежий курс.
2. **ex02. Аномалии**: найди операции, для которых нет пользователя или валюты.
3. **ex03. Classical DWH**: итоговый запрос (задание 00 проекта).

## Что отдать напарнику

Запрос из ex03, оформленный как представление `v_total_volume` (для общей сборки).

## Что получить от напарника

Представление `v_balance_usd` (его задание 01 проекта).

## Как работать

Данные в тренажёре уже загружены, ничего создавать не нужно. Таблицы: `"user"`, `currency`, `balance`.
