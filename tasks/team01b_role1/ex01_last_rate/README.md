# Задание 01. Последний курс

**Разрешено:** SQL

В таблице `currency` у валюты несколько строк: по одной на каждое изменение курса. Для каждой валюты верни **последний** курс.

Столбцы результата: `id`, `name`, `last_rate_to_usd`.

Отсортируй по `id`.

| id | name | last_rate_to_usd |
| --- | --- | --- |
| 100 | EUR | 0.9000 |
| 101 | USD | 1.0000 |
| … | … | … |
