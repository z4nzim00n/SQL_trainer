# Общая сборка: оба решения вместе

Роли выполнены. Теперь соберите итог в один скрипт, как если бы вы сдавали проект.

**Задание.** Напишите единый скрипт, который по порядку:

1. создаёт таблицу `nodes` и заполняет её рёбрами в обе стороны (часть Роли 1);
2. создаёт представление `v_all_tours` с рекурсивным запросом (часть Роли 2);
3. завершается запросом **обратной задачи**: маршруты с минимальной и с максимальной суммарной стоимостью, сортировка по `total_cost`, затем по `tour`.

Ожидаемый результат (4 города):

| total_cost | tour |
| --- | --- |
| 80 | {a,b,d,c,a} |
| 80 | {a,c,d,b,a} |
| 95 | {a,b,c,d,a} |
| 95 | {a,c,b,d,a} |
| 95 | {a,d,b,c,a} |
| 95 | {a,d,c,b,a} |

Здесь нет подготовленных данных: всё создаётся вашим скриптом с нуля.
