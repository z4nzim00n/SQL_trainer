# Теория: интеграция частей

Командная работа держится на **интерфейсах**: части совместимы, если совпадают имена и форма данных.

Здесь два интерфейса:

- таблица `nodes(point1, point2, cost)`: Архитектор отдаёт, Навигатор читает;
- представление `v_all_tours(total_cost, tour)`: Навигатор отдаёт, Архитектор читает.

**Порядок выполнения важен:** сначала таблица (иначе представлению нечего читать), потом представление, потом итоговый запрос.

Перед сдачей проверьте вдвоём:

1. скрипт выполняется «с чистого листа» без ошибок;
2. результат совпадает с таблицей из задания;
3. каждый может объяснить обе части (на защите спрашивают обоих про всё).

Бонус: в разделе Роли 1 есть проверка «пятый город». Прогоните собранный скрипт и на ней.

Ключевые слова для примеров: `CREATE TABLE`, `CREATE VIEW`, `WITH`, `CTE`, `UNION ALL`.
