## Идея

Склей три куска по порядку: данные, представление, итоговый запрос. Куски уже написаны вами в заданиях ролей.

## Каркас

```sql
-- 1) Роль 1: CREATE TABLE nodes ...; INSERT ...;
-- 2) Роль 2: CREATE VIEW v_all_tours AS WITH RECURSIVE ...;
-- 3) итог: SELECT ... min OR max ...;
```

## Почти ответ

Если скрипт падает, проверьте порядок и имена: таблица `nodes`, представление `v_all_tours`. Ошибка «relation does not exist» почти всегда означает неверный порядок или опечатку в имени.
