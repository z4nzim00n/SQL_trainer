# Задание 01. UNION ALL и сортировка частей

Сохранить дублирующиеся строки позволяет `UNION ALL`: он просто складывает результаты друг под другом и ничего не выбрасывает. Обычный `UNION` удалил бы повторы, а в меню название `cheese pizza` встречается много раз.

Общий `ORDER BY` в конце отсортировал бы весь список целиком и перемешал людей с пиццами. Нужна своя сортировка у каждой части. Для этого каждый `SELECT` вместе с его `ORDER BY` заключается в скобки: скобки превращают его в отдельный маленький запрос, у которого может быть собственная сортировка.

Внутри скобок `ORDER BY` видит только столбцы этого запроса. Если во второй части столбец называется `pizza_name`, то и сортировать нужно по `pizza_name`, а не по `object_name`: новое имя придумано в первой части, и вторая о нём ничего не знает.

Порядок частей задаёт порядок строк в результате: первой идёт часть с `person`, второй часть с `menu`. Название столбца результата, как и раньше, берётся из первого запроса.

## Примеры на маленьких таблицах

`UNION ALL` ничего не выбрасывает (в таблице `a` есть повторяющаяся строка `3, blue`):

```sql-run
SELECT val FROM a
UNION ALL
SELECT val FROM b;
```

Скобки дают каждой части свою сортировку:

```sql-run
(SELECT val FROM a ORDER BY val)
UNION ALL
(SELECT val FROM b ORDER BY val DESC);
```
