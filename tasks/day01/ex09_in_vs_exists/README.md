# Задание 09. IN против EXISTS

**Разрешено:** ANSI SQL

Напиши два SQL-запроса, которые возвращают список пиццерий, в которые **не заходили** люди:

1. первый запрос с оператором `IN` (то есть `NOT IN`);
2. второй запрос с оператором `EXISTS` (то есть `NOT EXISTS`).

В редакторе реши любым способом, потом перепиши вторым и сравни результат. Столбец результата: `name`.
