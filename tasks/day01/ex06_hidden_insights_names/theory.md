# Задание 06. Пересечение и JOIN вместе

Запрос из задания 03 уже даёт пары (дата, `person_id`). Чтобы получить имена, к этому результату нужно присоединить таблицу `person` по номеру человека.

Результат запроса можно поставить в `FROM` как временную таблицу: `FROM (запрос с INTERSECT) AS pv`. Псевдоним обязателен. Дальше к нему можно присоединять другие таблицы обычным `JOIN ... ON`.

`JOIN` оставляет строки, у которых нашлась пара в обеих таблицах. Условие после `ON` связывает номер человека из пересечения с `person.id`. Сортировать можно по новым именам из `SELECT`.

Ключевые слова для примеров: `JOIN`, `INTERSECT`, `AS`.
