# Задание 06. «Скрытые» инсайты с именами

**Разрешено:** ANSI SQL

Вернись к заданию 03 и измени запрос так, чтобы он возвращал **имена** людей вместо их идентификаторов.

Измени сортировку: сначала по дате действия (`action_date`) по возрастанию, затем по имени человека (`person_name`) по убыванию. Столбцы результата: `action_date`, `person_name`.

| action_date | person_name |
| --- | --- |
| 2022-01-01 | Irina |
| 2022-01-01 | Anna |
| 2022-01-01 | Andrey |
| … | … |
