# Задание 07. Просто сделай JOIN

**Разрешено:** ANSI SQL

Напиши SQL-запрос, который возвращает:

- дату заказа из таблицы `person_order` (столбец `order_date`);
- имя и возраст человека, сделавшего заказ, в формате `Имя (age:возраст)` (столбец `person_information`).

Отсортируй результат по обоим столбцам по возрастанию. Повторяющиеся строки сохрани: если человек сделал два заказа в один день, строка встречается два раза.

| order_date | person_information |
| --- | --- |
| 2022-01-01 | Andrey (age:21) |
| 2022-01-01 | Andrey (age:21) |
| 2022-01-01 | Anna (age:16) |
| … | … |
