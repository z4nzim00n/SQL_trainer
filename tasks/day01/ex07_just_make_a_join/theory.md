# Задание 07. JOIN ... ON

`JOIN` приклеивает к строке одной таблицы подходящие строки другой. Условие после `ON` говорит, какие строки подходят: здесь номер человека в заказе должен равняться `id` в таблице `person`.

```sql
FROM person_order
JOIN person ON person_order.person_id = person.id
```

На каждую строку заказа находится одна строка человека, поэтому число строк результата равно числу заказов, и повторы сохраняются сами собой (`DISTINCT` здесь не нужен).

`CONCAT(a, b, c)` склеивает значения в одну строку. Числа он превращает в текст сам. Формат `Андрей (age:21)` собирается из имени, текста `' (age:'`, возраста и текста `')'`.

Если в двух таблицах есть столбец с одним именем (`id`), пиши его с префиксом таблицы: `person.id`.

Ключевые слова для примеров: `JOIN`, `ON`, `CONCAT`, `ORDER BY`.
