# Задание 10. Глобальный JOIN

**Разрешено:** ANSI SQL

Напиши SQL-запрос, который вернёт список людей, заказавших пиццу, с указанием:

- имени клиента (`person_name`);
- названия пиццы (`pizza_name`);
- названия пиццерии (`pizzeria_name`).

Отсортируй результат по трём столбцам, все по возрастанию: `person_name`, `pizza_name`, `pizzeria_name`.

| person_name | pizza_name | pizzeria_name |
| --- | --- | --- |
| Andrey | cheese pizza | Dominos |
| Andrey | mushroom pizza | Dominos |
| Anna | cheese pizza | Pizza Hut |
| … | … | … |
