# Задание 10. Цепочка JOIN

Данные о заказе разбросаны по четырём таблицам:

- `person_order` хранит, кто (`person_id`) и что (`menu_id`) заказал;
- `person` даёт имя по `person_id`;
- `menu` даёт название пиццы и номер пиццерии по `menu_id`;
- `pizzeria` даёт название пиццерии по `pizzeria_id`.

Таблицы соединяют цепочкой: каждое следующее `JOIN` привязывается к уже собранной части.

```sql
FROM person_order
JOIN person ON ...
JOIN menu ON ...
JOIN pizzeria ON ...
```

Столбец `name` есть и в `person`, и в `pizzeria`, поэтому в `SELECT` их пишут с префиксами и переименовывают через `AS`. Сортировать можно по нескольким столбцам сразу, у каждого своё направление.

Ключевые слова для примеров: `JOIN`, `ON`, `AS`, `ORDER BY`.
