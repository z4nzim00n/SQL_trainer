# Задание 04. EXCEPT ALL

`EXCEPT` возвращает строки первого запроса, которых нет во втором. **Порядок запросов важен**: `A EXCEPT B` и `B EXCEPT A` дают разное. В Oracle то же самое называется `MINUS`.

Обычный `EXCEPT` убирает повторы. `EXCEPT ALL` вычитает **по количеству**: если значение встречается в первом запросе 3 раза, а во втором 1 раз, то в результате останется 2 копии. Так работают мультимножества: у элемента есть кратность.

Условие по дате стоит в каждом запросе отдельно. `JOIN` запрещён.

Ключевые слова для примеров: `EXCEPT`, `EXCEPT ALL`, `WHERE`.
