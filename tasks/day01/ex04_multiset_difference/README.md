# Задание 04. Разность мультимножеств

**Разрешено:** ANSI SQL

**Запрещено:** все виды `JOIN`

Напиши SQL-запрос, который вернёт разницу (операция `MINUS`, в PostgreSQL `EXCEPT`) по значениям столбца `person_id` между таблицами `person_order` и `person_visits`, **сохраняя дубликаты**.

Нужны только записи за 7 января 2022 года:

- для `person_order`: `order_date = '2022-01-07'`;
- для `person_visits`: `visit_date = '2022-01-07'`.

Столбец результата: `person_id`. Порядок строк не важен.
