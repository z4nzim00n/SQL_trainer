# Задание 03. INTERSECT: пересечение

`INTERSECT` оставляет только те строки, которые есть **в обоих** результатах. Сравниваются строки целиком (по всем столбцам), поэтому нужно выбрать в обоих запросах одинаковые по смыслу столбцы: дату и номер человека.

Названия столбцов результата берутся из первого запроса, поэтому дату переименовывают там: `order_date AS action_date`. `ORDER BY` пишется один раз в самом конце и может ссылаться на это новое имя. Сортировать можно по нескольким столбцам с разным направлением: `ORDER BY a ASC, b DESC`.

`INTERSECT` без `ALL` сам убирает повторы, как `DISTINCT`. Здесь `JOIN` запрещён: пересечение множеств даёт то, что обычно получают соединением.

Ключевые слова для примеров: `INTERSECT`, `AS`, `ORDER BY`.
