# Задание 03. «Скрытые» инсайты

**Разрешено:** ANSI SQL

**Запрещено:** все виды `JOIN`

Напиши SQL-запрос, который находит **пересечение** данных по:

- дате заказа (`order_date`) и идентификатору человека (`person_id`) из таблицы `person_order`;
- дате визита (`visit_date`) и идентификатору человека (`person_id`) из таблицы `person_visits`.

Проще говоря, нужно найти людей, которые в один и тот же день и посетили заведение, и сделали заказ пиццы.

Результат отсортируй сначала по дате действия (`action_date`) по возрастанию, затем по `person_id` по убыванию. Столбцы результата: `action_date`, `person_id`.

| action_date | person_id |
| --- | --- |
| 2022-01-01 | 6 |
| 2022-01-01 | 2 |
| 2022-01-01 | 1 |
| 2022-01-03 | 7 |
| … | … |
