# Задание 08. NATURAL JOIN

`NATURAL JOIN` соединяет таблицы **автоматически по всем столбцам с одинаковыми названиями**. Условие `ON` писать не нужно.

Проблема: в нашей базе в каждой таблице есть `id`. Поэтому `person_order NATURAL JOIN person` соединит по `id`, то есть номер заказа сравнит с номером человека. Это бессмыслица, и результат будет странным или пустым.

Чтобы соединение шло по нужному столбцу, переименуй столбцы так, чтобы совпадал только он. Например, возьми подзапрос из `person`, в котором `id` назван `person_id`:

```sql
NATURAL JOIN (SELECT id AS person_id, name, age FROM person) AS p
```

Теперь у `person_order` и подзапроса одинаково называется только `person_id`, и соединение идёт именно по нему. Подзапросу в `FROM` нужен псевдоним.

В реальных проектах `NATURAL JOIN` обычно избегают: если когда-нибудь добавится столбец с таким же названием, запрос тихо изменит смысл.

Ключевые слова для примеров: `NATURAL JOIN`, `AS`.
