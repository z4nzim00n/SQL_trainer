# Задание 03. Посещения: даты или пиццерия

**Разрешено:** ANSI SQL

Составь запрос `SELECT`, который вернёт **уникальные** идентификаторы людей (без дубликатов), посетивших пиццерии в период с 6 по 9 января 2022 года (включительно), **либо** посетивших пиццерию с идентификатором 2.

Результат отсортируй по идентификатору человека по убыванию.
