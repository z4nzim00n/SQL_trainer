# Задание 03. OR, DISTINCT и даты

`OR` пропускает строку, если верно **хотя бы одно** из условий (в отличие от `AND`, где нужны оба). Если в условии смешиваются `AND` и `OR`, ставь скобки: у `AND` приоритет выше.

Один человек мог посетить пиццерии несколько раз, поэтому его `person_id` в результате повторяется. `DISTINCT` после слова `SELECT` оставляет только разные значения.

Даты пишутся в одинарных кавычках в виде `'2022-01-06'` и сравниваются так же, как числа; `BETWEEN` для дат тоже включает обе границы.

## Примеры на маленьких таблицах

Повторы без `DISTINCT` и с ним:

```sql-run
SELECT city FROM students;
```

```sql-run
SELECT DISTINCT city
FROM students
ORDER BY city DESC;
```

Условие с `OR` и диапазоном дат:

```sql-run
SELECT title, added
FROM products
WHERE added BETWEEN '2024-01-01' AND '2024-01-31' OR category = 'travel';
```
