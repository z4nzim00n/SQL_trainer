# Задание 07. CASE с несколькими ветками

В `CASE` может быть сколько угодно веток `WHEN`:

```sql
CASE
    WHEN условие_1 THEN значение_1
    WHEN условие_2 THEN значение_2
    ELSE значение_по_умолчанию
END
```

Проверка идёт сверху вниз, срабатывает **первая** верная ветка, остальные уже не смотрятся. Поэтому в `ELSE if` из псевдокода во второй ветке не нужно повторять, что возраст больше 20: до неё доходят только те, кому первая ветка не подошла (но условие всё равно можно записать полностью, как в задании).

Границы важны. `>= 10 AND <= 20` включает 10 и 20, а `> 20 AND < 24` их не включает. Подумай, в какой интервал попадёт возраст ровно 20, ровно 21 или ровно 24.

Результат `CASE` это значение, поэтому ему нужно имя через `AS`, и по этому имени можно сортировать. Текстовые значения сортируются как обычный текст: `interval #1` раньше `interval #2`.

## Примеры на маленьких таблицах

```sql-run
SELECT name, age,
       CASE
           WHEN age < 20 THEN 'young'
           WHEN age < 25 THEN 'middle'
           ELSE 'older'
       END AS age_group
FROM students
ORDER BY age_group, name;
```
