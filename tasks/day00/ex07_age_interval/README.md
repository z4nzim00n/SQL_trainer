# Задание 07. Интервалы возраста

**Разрешено:** ANSI SQL

Применим интервалы возрастов к таблице `person`.

Напиши запрос, который вернёт идентификаторы людей, их имена и интервал по возрасту в виде нового вычисляемого столбца `interval_info` по псевдокоду:

```
if (age >= 10 and age <= 20) - вернуть «interval #1»
else if (age > 20 and age < 24) - вернуть «interval #2»
во всех остальных случаях - вернуть «interval #3»
```

Отсортируй результат по столбцу `interval_info` по возрастанию. Столбцы результата: `id`, `name`, `interval_info`. (Порядок людей внутри одного интервала не важен.)
