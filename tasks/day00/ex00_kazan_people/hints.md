## Идея

Нужна таблица `person`. Покажи из неё два столбца: имя и возраст. Оставь только тех, у кого город равен `'Kazan'`.

## Каркас

```sql
SELECT ______, ______
FROM ______
WHERE ______ = '______';
```

Впиши названия двух столбцов, таблицу, столбец с городом и само значение.

## Почти ответ

```sql
SELECT name, age
FROM person
WHERE ______ = 'Kazan';
```

Осталось название столбца, в котором хранится город.
