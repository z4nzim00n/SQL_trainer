# Задание 00. SELECT, FROM, WHERE

Запрос `SELECT` только читает данные. Он отвечает на три вопроса: какие столбцы показать (`SELECT`), из какой таблицы (`FROM`) и какие строки оставить (`WHERE`).

Столбцы перечисляются через запятую. Условие в `WHERE` сравнивает значение столбца с тем, что нужно найти. Текст пишется в **одинарных** кавычках и сравнивается с учётом регистра: `'Kazan'` и `'kazan'` для базы разные значения. Сравнение на равенство это одно знаком `=`, а не два.

Таблицы базы и их столбцы смотри на вкладке «Схема БД» справа внизу: нужные данные о людях лежат в таблице `person`.

## Примеры на маленьких таблицах

Выбрать два столбца:

```sql-run
SELECT name, city
FROM students;
```

Оставить только строки, где город равен `'Berlin'`:

```sql-run
SELECT name, age
FROM students
WHERE city = 'Berlin';
```
