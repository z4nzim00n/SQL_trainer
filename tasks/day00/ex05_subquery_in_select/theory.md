# Задание 05. Подзапрос в части SELECT

**Подзапрос** это `SELECT` внутри другого запроса, в скобках. Если он стоит в списке столбцов, то вычисляется для каждой строки внешнего запроса и должен возвращать **одно значение** (одну строку и один столбец).

Подзапрос может обращаться к столбцам внешней строки. Так он узнаёт, для какого человека искать имя: в условии внутри пишут `person.id = person_order.person_id`, то есть сравнивают `id` из `person` со значением из текущей строки внешней таблицы.

В заказах хранится только `person_id`, а имя лежит в `person`. Внутренний запрос и достаёт имя по этому номеру, поэтому `JOIN` здесь не нужен (он запрещён).

Если условие состоит из нескольких вариантов одного столбца без `IN`, их перечисляют через `OR`: `menu_id = 13 OR menu_id = 14`. Вместе с другим условием через `AND` такой `OR` берут в скобки.

## Примеры на маленьких таблицах

Название курса достаём подзапросом в `SELECT`:

```sql-run
SELECT name,
       (SELECT title FROM courses WHERE courses.id = students.course_id) AS course
FROM students
ORDER BY name;
```

У Eve нет курса, подзапрос вернул `NULL`. Условия с `OR` и `AND` вместе (скобки обязательны):

```sql-run
SELECT name, age
FROM students
WHERE (city = 'Berlin' OR city = 'Rome') AND age >= 20
ORDER BY name;
```
