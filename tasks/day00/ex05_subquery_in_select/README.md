# Задание 05. Подзапрос в SELECT

**Разрешено:** ANSI SQL

**Запрещено:** `IN`, все виды `JOIN`

Напиши запрос `SELECT`, который вернёт имена людей (используя внутренний запрос в части `SELECT`), которые сделали заказы по меню с идентификаторами 13, 14 и 18, при этом дата заказа должна быть 7 января 2022 года.

Столбец результата назови `name`. Перед началом работы обязательно ознакомься с разделом «Запрещено».

Обрати внимание на пример внутреннего запроса:

```sql
SELECT
    (SELECT ... ) AS name  -- это внутренний запрос в основном операторе
FROM ...
WHERE ...
```
