# Задание 01. AND и ORDER BY

Если нужно, чтобы выполнялись сразу два условия, их соединяют словом `AND`. Строка попадёт в результат, только если верны оба условия.

`ORDER BY` сортирует готовый результат. Пишется он в самом конце запроса, после `WHERE`. По умолчанию сортировка по возрастанию (для текста это алфавитный порядок); слово `DESC` разворачивает её.

Не путай: `WHERE` отбирает строки, а `ORDER BY` только меняет порядок уже отобранных.

## Примеры на маленьких таблицах

Два условия сразу:

```sql-run
SELECT name, age, city
FROM students
WHERE city = 'Berlin' AND age > 19;
```

Сортировка по имени:

```sql-run
SELECT name, age
FROM students
ORDER BY name;
```
