# Задание 09. Подзапрос в FROM

**Разрешено:** ANSI SQL

**Запрещено:** все виды `JOIN`

Составь запрос `SELECT`, который вернёт имена людей и названия пиццерий на основе таблицы `person_visits` с датами посещений в период с 7 по 9 января 2022 года (включительно), используя внутренний запрос в части `FROM`.

Обрати внимание на структуру итогового запроса:

```sql
SELECT (...) AS person_name,    -- внутренний запрос в основном SELECT
       (...) AS pizzeria_name   -- внутренний запрос в основном SELECT
FROM (SELECT ... FROM person_visits WHERE ...) AS pv  -- внутренний запрос в основном FROM
ORDER BY ...
```

Добавь сортировку по имени человека по возрастанию и по названию пиццерии по убыванию.
