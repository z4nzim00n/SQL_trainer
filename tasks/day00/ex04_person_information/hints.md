## Идея

Нужно собрать одну строку из пяти кусков: имя, возраст, пол, адрес и постоянный текст между ними. Для склейки удобен `CONCAT`. Одинарные кавычки внутри текста удваиваются.

## Каркас

```sql
SELECT CONCAT(name, ' (age:', ______, ',gender:''', ______, ''',address:''', ______, ''')') AS ______
FROM person
ORDER BY ______;
```

Впиши три столбца и название вычисляемого поля (оно же в сортировке).

## Почти ответ

```sql
SELECT CONCAT(name, ' (age:', age, ',gender:''', gender, ''',address:''', address, ''')') AS person_information
FROM person
ORDER BY ______;
```

Осталась сортировка по новому имени столбца.
