# Задание 04. Склейка текста и кавычки

Строки склеиваются функцией `CONCAT(a, b, c, ...)`: она принимает любое число значений, сама превращает числа в текст и считает `NULL` пустой строкой. Есть и оператор `||`: `name || ' ' || city`. Но с `NULL` он даёт `NULL`, а числа ему нужно превращать в текст вручную.

Текст пишется в одинарных кавычках. Если сам текст должен содержать одинарную кавычку, её удваивают: `''`. Так `'gender:'''` это строка `gender:'`: открывающая кавычка, текст `gender:`, затем удвоенная кавычка (одна настоящая кавычка в тексте) и закрывающая.

`AS имя` задаёт название столбца результата. По этому имени можно сортировать в `ORDER BY`.

## Примеры на маленьких таблицах

Склейка значений из разных столбцов:

```sql-run
SELECT CONCAT(name, ' (age:', age, ')') AS info
FROM students
ORDER BY info;
```

Кавычка внутри текста (удвоенная):

```sql-run
SELECT CONCAT(name, ' lives in ''', city, '''') AS info
FROM students
WHERE city IS NOT NULL
ORDER BY info;
```
