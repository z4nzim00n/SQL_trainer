# Задание 06. CASE и логическое значение

Выражение `CASE` это `if / else` внутри запроса:

```sql
CASE WHEN условие THEN значение_1 ELSE значение_2 END
```

Условия проверяются сверху вниз, срабатывает первое верное. Значениями могут быть и логические `true` / `false`.

Само сравнение тоже даёт логическое значение: `name = 'Denis'` это `true` или `false` (а при `NULL` слева результат тоже `NULL`). Так что проверку можно записать и коротко, без `CASE`.

Подзапрос из задания 05 можно использовать и внутри `CASE`: в условии вместо имени столбца стоит тот же подзапрос в скобках. Новое имя `person_name` из `SELECT` нельзя использовать в условии `WHERE` или внутри другого выражения `SELECT` (оно ещё не создано), поэтому подзапрос приходится повторить.

## Примеры на маленьких таблицах

`CASE` с логическим результатом:

```sql-run
SELECT name,
       CASE WHEN name = 'Ann' THEN true ELSE false END AS is_ann
FROM students
ORDER BY name;
```

Короткая запись: сравнение само даёт `true` или `false`:

```sql-run
SELECT name, (age >= 21) AS is_adult
FROM students
ORDER BY name;
```
