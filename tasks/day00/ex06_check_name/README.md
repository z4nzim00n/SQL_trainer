# Задание 06. Проверка имени

**Разрешено:** ANSI SQL

**Запрещено:** `IN`, все виды `JOIN`

Используй конструкцию SQL из задания 05 и добавь в оператор `SELECT` новый вычисляемый столбец с именем `check_name`. В этом столбце реализуй проверку по псевдокоду:

```
if (person_name == 'Denis') вернуть true,
иначе вернуть false.
```

Столбец с именем человека в этом задании называется `person_name` (он нужен в результате вместе с `check_name`). Условия отбора заказов те же, что в задании 05.
