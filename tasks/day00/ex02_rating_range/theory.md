# Задание 02. Сравнения и BETWEEN

Значения можно сравнивать: `>` больше, `<` меньше, `>=` больше или равно, `<=` меньше или равно. Границы «включительно» означают именно `>=` и `<=`; строгие `>` и `<` границу бы не включили.

Для диапазона есть короткая запись `BETWEEN a AND b`. Она значит то же, что `>= a AND <= b`: **обе границы включаются**.

Для сортировки по числу `ORDER BY` работает так же, как для текста: по возрастанию по умолчанию.

## Примеры на маленьких таблицах

Через операторы сравнения:

```sql-run
SELECT title, price
FROM products
WHERE price >= 4 AND price <= 20
ORDER BY price;
```

Тот же результат через `BETWEEN`:

```sql-run
SELECT title, price
FROM products
WHERE price BETWEEN 4 AND 20
ORDER BY price;
```
