# Задание 02. Рейтинг от 3.5 до 5

**Разрешено:** ANSI SQL

Составь запрос `SELECT`, который вернёт список пиццерий (название и рейтинг) с рейтингом от 3.5 до 5 включительно, отсортированный по рейтингу.

В оригинальном задании нужно написать **два запроса**, разных по синтаксису:

1. В первом используй операторы сравнения (`<=`, `>=`).
2. Во втором используй ключевое слово `BETWEEN`.

В редакторе реши задание любым из способов, потом перепиши вторым способом и убедись, что результат тот же (автопроверка принимает оба).
