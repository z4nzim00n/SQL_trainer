## Идея

Нужны все столбцы (`*`) таблицы `person_order`. Условие чётности через остаток от деления на 2. Сортировка по `id`.

## Каркас

```sql
SELECT ______
FROM person_order
WHERE id ______ 2 = ______
ORDER BY ______;
```

Впиши «все столбцы», оператор остатка, число для чётных и столбец сортировки.

## Почти ответ

```sql
SELECT *
FROM person_order
WHERE id % 2 = ______
ORDER BY id;
```

Осталось число: какой остаток у чётных чисел.
