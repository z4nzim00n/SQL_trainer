# Задание 08. Остаток от деления

Число чётное, если при делении на 2 остаток равен нулю. Остаток даёт оператор `%`: `10 % 2` это `0`, `7 % 2` это `1`. То же делает функция `MOD(10, 2)`.

Поэтому условие «`id` чётный» записывается как `id % 2 = 0`. Звёздочка `*` в `SELECT` означает «все столбцы таблицы».

Не путай `%` в арифметике с `%` в шаблонах `LIKE`: в `LIKE` это любое количество символов, а между числами остаток от деления.

## Примеры на маленьких таблицах

```sql-run
SELECT id, title
FROM products
WHERE id % 2 = 0
ORDER BY id;
```

Нечётные тем же приёмом:

```sql-run
SELECT *
FROM products
WHERE MOD(id, 2) = 1
ORDER BY id;
```
