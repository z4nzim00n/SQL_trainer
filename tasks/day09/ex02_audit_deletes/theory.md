# Задание 02. Триггер на DELETE

При `DELETE` у триггера есть только `OLD`: строка, которая вот-вот будет (или только что была) удалена. `NEW` при удалении не существует.

Для журнала это главный случай: после удаления данных нигде больше нет, и аудит остаётся единственным местом, где можно увидеть, что именно удалили и когда.

Заметь схему: три триггера на одну таблицу делают одно и то же с разными значениями. Следующее задание объединит их в один.

Ключевые слова для примеров: `CREATE TRIGGER`, `CREATE FUNCTION`, `DELETE`.
