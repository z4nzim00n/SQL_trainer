# Задание 00. Триггеры и триггерные функции

**Триггер** это правило «когда в таблице случилось событие, автоматически выполни функцию». Он нужен для аудита, автоматических расчётов, защиты данных.

Создаются два объекта:

**1. Триггерная функция.** Возвращает специальный тип `trigger`, пишется на `plpgsql`:

```sql
CREATE FUNCTION имя() RETURNS trigger AS $$
BEGIN
    ... тело ...
    RETURN NULL;
END;
$$ LANGUAGE plpgsql;
```

Внутри доступны служебные переменные: `NEW` (новая строка, при `INSERT` и `UPDATE`), `OLD` (старая строка, при `UPDATE` и `DELETE`), `TG_OP` (название операции).

**2. Триггер**: привязка функции к таблице и событию:

```sql
CREATE TRIGGER имя AFTER INSERT ON таблица
FOR EACH ROW EXECUTE FUNCTION имя_функции();
```

- `AFTER` / `BEFORE`: срабатывать после или до самой операции;
- `FOR EACH ROW`: один раз на **каждую строку** (иначе `FOR EACH STATEMENT`: один раз на весь оператор, и `NEW` недоступен);
- `RETURN NULL` для `AFTER`-триггера нормален: результат игнорируется.

В теле `$$ ... $$`: так называемые «долларовые кавычки», внутри которых можно спокойно писать апострофы.

В `person_audit` значения по умолчанию (`created`, `type_event`) подставятся сами, если не указать эти столбцы в `INSERT`.

Ключевые слова для примеров: `CREATE FUNCTION`, `CREATE TRIGGER`, `TRIGGER`, `CHECK`, `DEFAULT`, `NOT NULL`.
