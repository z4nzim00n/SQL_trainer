# Задание 07. Минимум по-другому

**Язык:** SQL, DDL, DML

Напиши функцию на SQL или PL/pgSQL (на твой выбор) с именем `func_minimum`, которая принимает входной параметр **в виде массива чисел** и возвращает **минимальное значение**.

Проверка:

```sql
SELECT func_minimum(VARIADIC arr => ARRAY[10.0, -1.0, 5.0, 4.4]);
```

Параметр называется `arr`.
