# Задание 07. Массивы и VARIADIC

**Массив** это упорядоченный набор значений одного типа. В PostgreSQL: тип с квадратными скобками (`numeric[]`), литерал `ARRAY[10.0, -1.0, 5.0]`.

`VARIADIC` в объявлении параметра значит «функция принимает любое число аргументов, внутри они собраны в массив»:

```sql
CREATE FUNCTION func_minimum(VARIADIC arr numeric[]) RETURNS numeric AS $$
    SELECT MIN(a) FROM unnest(arr) AS a;
$$ LANGUAGE sql;
```

Вызывать её можно двумя способами:

- перечислив значения: `func_minimum(3.5, 2.25, 9.0)`;
- передав готовый массив с ключевым словом: `func_minimum(VARIADIC arr => ARRAY[10.0, -1.0, 5.0])`.

`unnest(массив)` разворачивает массив в таблицу из одного столбца (по строке на элемент), после чего обычный `MIN` находит минимум.

Ключевые слова для примеров: `CREATE FUNCTION`, `MIN`, `FUNCTION`.
