# Задание 05. Функция с параметром

**Язык:** SQL, DDL, DML

Двум функциям из задания 04 нужно более универсальное решение. Перед продолжением **удали** эти функции из базы.

Напиши универсальную **SQL-функцию** (не plpgsql) `fnc_persons` с входным параметром `pgender`, у которого значение по умолчанию `'female'`.

Проверка:

```sql
SELECT * FROM fnc_persons(pgender := 'male');
SELECT * FROM fnc_persons();
```
