# Задание 08. Алгоритм Фибоначчи в функции

**Язык:** SQL, DDL, DML

Напиши функцию на SQL или PL/pgSQL (на твой выбор) `fnc_fibonacci` с входным параметром `pstop` типа `integer` (по умолчанию `10`), которая возвращает **таблицу** всех чисел Фибоначчи, **меньших** `pstop`. Последовательность начинается с `0, 1, 1, 2, 3, 5, 8, …`.

Для `pstop = 10` результат: `0, 1, 1, 2, 3, 5, 8`.

Проверка:

```sql
SELECT * FROM fnc_fibonacci(100);
SELECT * FROM fnc_fibonacci();
```
