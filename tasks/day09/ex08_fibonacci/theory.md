# Задание 08. Рекурсия и циклы

Каждое следующее число Фибоначчи это сумма двух предыдущих. Есть два естественных способа получить ряд.

**1. Рекурсивный запрос (`WITH RECURSIVE`) на SQL.** Часть до `UNION ALL` задаёт стартовую строку, часть после описывает, как получить следующую строку из предыдущей. Рекурсия идёт, пока выполняется условие в `WHERE`:

```sql
WITH RECURSIVE fib(a, b) AS (
    SELECT 0, 1
    UNION ALL
    SELECT b, a + b FROM fib WHERE a < pstop
)
SELECT a FROM fib WHERE a < pstop;
```

Пара `(a, b)` хранит два соседних числа: из `(0, 1)` получается `(1, 1)`, затем `(1, 2)`, `(2, 3)` и так далее. В результат берём `a`.

**2. Цикл на plpgsql.** Две переменные и `WHILE`:

```sql
WHILE a < pstop LOOP
    RETURN NEXT a;
    ...
END LOOP;
```

Граница строгая: числа **меньше** `pstop`. Для `pstop = 8` число 8 уже не входит.

Ключевые слова для примеров: `CREATE FUNCTION`, `WITH`, `UNION ALL`, `CTE`, `FUNCTION`.
