# Задание 06. plpgsql-функция, возвращающая таблицу

`plpgsql` это процедурное расширение SQL: тело функции состоит из блока `BEGIN ... END;`, а результат запроса отдают командой `RETURN QUERY`.

```sql
CREATE FUNCTION имя(IN a тип DEFAULT значение, ...)
RETURNS TABLE (столбец тип) AS $$
BEGIN
    RETURN QUERY SELECT ... ;
END;
$$ LANGUAGE plpgsql;
```

- `RETURNS TABLE (...)`: описывает столбцы результата. Типы столбцов запроса должны **совпадать** с описанными (поэтому у нас `varchar`, как у `pizzeria.name`);
- `IN`: входной параметр (по умолчанию все параметры такие); `DEFAULT` задаёт значение, когда параметр не передан;
- в теле параметры используются по имени. Их имена не должны совпадать со столбцами таблиц, иначе возникнет неоднозначность: поэтому принято префиксное `p...`.

Чем plpgsql отличается от `LANGUAGE sql`: можно писать циклы, условия, переменные, исключения. Для простого «обернуть запрос параметрами» хватило бы и sql, но здесь требуется plpgsql.

Ключевые слова для примеров: `CREATE FUNCTION`, `FUNCTION`, `DEFAULT`, `DISTINCT`, `JOIN`.
