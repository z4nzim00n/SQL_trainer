# Задание 06. Функция-обёртка

**Язык:** SQL, DDL, DML

Теперь рассмотрим функции **plpgsql**. Создай функцию `fnc_person_visits_and_eats_on_date` (на `plpgsql`, на основе SQL-запроса), которая находит **названия пиццерий**, которые посетил человек, и где он мог купить пиццу **дешевле** указанной суммы на заданную дату:

- `IN pperson`: имя человека, по умолчанию `'Dmitriy'`;
- `IN pprice`: предельная сумма в рублях, по умолчанию `500`;
- `IN pdate`: дата посещения, по умолчанию `8 января 2022 года`.

Каждая пиццерия должна быть в результате **не более одного раза**.

Проверка:

```sql
SELECT * FROM fnc_person_visits_and_eats_on_date(pprice := 800);
SELECT * FROM fnc_person_visits_and_eats_on_date(pperson := 'Anna', pprice := 1300, pdate := '2022-01-01');
```
