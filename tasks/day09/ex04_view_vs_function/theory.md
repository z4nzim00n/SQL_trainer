# Задание 04. Функция, возвращающая таблицу

Функция может возвращать не одно значение, а **набор строк**, и тогда её ставят в `FROM`, как таблицу.

```sql
CREATE FUNCTION имя() RETURNS SETOF person AS $$
    SELECT * FROM person WHERE gender = 'male';
$$ LANGUAGE sql;
```

- `RETURNS SETOF person`: вернуть набор строк типа «строка таблицы `person`» (альтернатива: `RETURNS TABLE(id bigint, name varchar, ...)`);
- `LANGUAGE sql`: тело это просто запрос, результат последнего запроса и есть результат функции. Никаких `BEGIN`, `RETURN` не нужно;
- тело заключено в `$$ ... $$`.

Отличие от представления: функции можно передавать параметры (это следующее задание), а представление всегда одно и то же. Зато представление проще и обычно эффективнее для простой фильтрации.

Ключевые слова для примеров: `CREATE FUNCTION`, `FUNCTION`, `WHERE`.
