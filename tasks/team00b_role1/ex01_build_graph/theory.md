# Теория: DDL для таблицы рёбер

`CREATE TABLE` создаёт таблицу, `INSERT INTO ... VALUES` наполняет её. Один оператор `INSERT` может вставить сразу много строк: значения перечисляются через запятую.

Тип столбца для названий городов: текстовый (`varchar`). Для стоимости: число (`integer`). Ограничение `NOT NULL` запрещает пропуски: у ребра обязательно есть начало, конец и стоимость.

Ошибка №1 в таких заданиях: забыть обратное направление. Если внести только `(a, b, 10)`, из города `b` в `a` проехать будет нельзя, и маршруты, возвращающиеся в начало, не найдутся.

Ключевые слова для примеров: `CREATE TABLE`, `INSERT`, `NOT NULL`.
