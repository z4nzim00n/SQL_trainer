# Задание 01 (Роль 1). Построй граф

**Язык:** ANSI SQL, DDL, DML

Создай таблицу `nodes` со столбцами `point1`, `point2`, `cost` (откуда, куда, стоимость) и заполни её данными по картинке: для каждого ребра внеси **две строки**, по одной в каждую сторону.

```
        10
   a --------- b
   | \       / |
15 |   \ 20 /   | 25
   |     X     |
   |   /   \   |
   c --------- d
        30
   (b–c: 35)
```

Рёбра графа (стоимость одинакова в обе стороны):

| Пара | Стоимость |
| --- | --- |
| a – b | 10 |
| a – c | 15 |
| a – d | 20 |
| b – c | 35 |
| b – d | 25 |
| c – d | 30 |

Должно получиться **12 строк**.

> Именно эту таблицу будет использовать Навигатор (Роль 2). Названия таблицы и столбцов менять нельзя: это условие договорённости.
