# Задание 02 (Роль 1). Классическая задача: самые дешёвые маршруты

**Язык:** ANSI SQL

Таблица `nodes` и представление `v_all_tours` (столбцы `total_cost`, `tour`; его пишет Роль 2) уже подготовлены: в нём **все** маршруты из города `a`, которые обходят все города и возвращаются в `a`.

Напиши запрос, который возвращает **только маршруты с минимальной суммарной стоимостью**. Отсортируй результат по `total_cost`, затем по `tour`.

| total_cost | tour |
| --- | --- |
| 80 | {a,b,d,c,a} |
| 80 | {a,c,d,b,a} |

Таких маршрутов может быть несколько: нужны **все** лучшие, а не один.
