# Теория: все строки с минимальным значением

Чтобы выбрать строки с минимальной стоимостью, сначала найди минимум подзапросом, затем оставь строки, равные ему:

```sql
SELECT total_cost, tour
FROM v_all_tours
WHERE total_cost = (SELECT MIN(total_cost) FROM v_all_tours)
ORDER BY total_cost, tour;
```

Сравни с `ORDER BY total_cost LIMIT 1`: он вернёт **одну** строку и потеряет остальные лучшие маршруты. А маршруты `a → b → d → c → a` и обратный `a → c → d → b → a` имеют одинаковую стоимость, значит, правильный ответ содержит оба.

Сортировка по массиву `tour` работает: массивы сравниваются поэлементно слева направо.

Ключевые слова для примеров: `MIN`, `ORDER BY`, `LIMIT`, `VIEW`.
