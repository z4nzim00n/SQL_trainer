# Задание 01 (Роль 2). Все маршруты

**Язык:** ANSI SQL, DDL

**Шаблон синтаксиса:** рекурсивный запрос

Таблица `nodes(point1, point2, cost)` с рёбрами графа (в обе стороны) уже подготовлена. Создай представление `v_all_tours` со столбцами:

- `total_cost`: суммарная стоимость маршрута;
- `tour`: массив городов, например `{a,b,d,c,a}`.

В представлении должны быть **все** маршруты, которые:

- начинаются в городе `a`;
- проходят через каждый город ровно один раз;
- возвращаются в `a`.

Для четырёх городов это 6 маршрутов. Представление должно работать и для **другого числа городов**: число городов нельзя вписывать числом.

```
        10
   a --------- b
   | \       / |
15 |   \ 20 /   | 25
   |     X     |
   |   /   \   |
   c --------- d
        30
   (b–c: 35)
```

Рёбра графа (стоимость одинакова в обе стороны):

| Пара | Стоимость |
| --- | --- |
| a – b | 10 |
| a – c | 15 |
| a – d | 20 |
| b – c | 35 |
| b – d | 25 |
| c – d | 30 |

> Тренажёр проверяет представление на этих данных, а затем сам добавляет пятый город и проверяет, что результат пересчитался (24 маршрута).
