# Теория: рекурсивное построение маршрутов

Подробная схема рекурсии есть в карточке роли (вкладка «Теория» первого задания Роли 2). Здесь главное в короткой форме.

**Три составные части**

1. Стартовая часть: все рёбра из `a`. Путь пока из двух городов.
2. Рекурсивная часть: к каждому пути присоединяем ребро в город, которого в пути ещё нет (`NOT point2 = ANY (path)`).
3. Финальный `SELECT`: оставляем пути длиной «все города» и замыкаем возвратом в `a`.

**Как не «зашить» число городов.** Число городов считается так:

```sql
SELECT COUNT(*) FROM (SELECT point1 FROM nodes UNION SELECT point2 FROM nodes) AS cities
```

Это значение сравнивается с `CARDINALITY(path)`.

**Типичные ошибки**

- нет проверки «уже был»: рекурсия бесконечна;
- не добавлена стоимость последнего ребра (возврат в `a`);
- маршруты начинаются не только в `a`;
- вписано число 4: на 5 городах решение ломается.

Ключевые слова для примеров: `WITH`, `CTE`, `UNION ALL`, `ANY`, `CREATE VIEW`.
