# Задание 03 (Роль 2). Старт из любого города

**Язык:** ANSI SQL, DDL

Сделай запрос универсальным: оформи его как **SQL-функцию** `fnc_tours` с параметром `pstart` (город, откуда стартует маршрут; значение по умолчанию `'a'`). Функция возвращает таблицу (`total_cost integer`, `tour varchar[]`) со всеми маршрутами, которые стартуют в `pstart`, обходят все города и возвращаются в `pstart`.

Проверка:

```sql
SELECT * FROM fnc_tours();
SELECT * FROM fnc_tours('c');
SELECT * FROM fnc_tours(pstart := 'b');
```

> Таблица `nodes` подготовлена. Тренажёр вызывает функцию с разными стартами и на 4, и на 5 городах.
