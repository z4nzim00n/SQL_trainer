# Теория: параметризация

Это тема из Day 09: функции с параметрами и значениями по умолчанию.

```sql
CREATE FUNCTION fnc_tours(pstart varchar DEFAULT 'a')
RETURNS TABLE (total_cost integer, tour varchar[]) AS $$
    WITH RECURSIVE ... WHERE point1 = pstart ...
$$ LANGUAGE sql;
```

Что поменять в запросе из задания 01:

- стартовую точку `'a'` заменить на параметр `pstart` (и в стартовой части рекурсии, и при возврате в конце);
- типы столбцов результата должны совпасть с `RETURNS TABLE`: сумма целых это `integer` (при необходимости приведи через `::integer`), массив городов это `varchar[]`.

Теперь одну и ту же логику можно применить к любому городу. Для симметричного графа стоимости маршрутов от разных стартов совпадают (маршрут тот же, просто «повёрнут»).

Ключевые слова для примеров: `CREATE FUNCTION`, `DEFAULT`, `WITH`, `CTE`.
