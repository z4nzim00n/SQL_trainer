# Теория: два экстремума в одном запросе

Нужны строки, чья стоимость равна минимуму **или** максимуму. Два подзапроса соединяются через `OR`:

```sql
SELECT total_cost, tour
FROM v_all_tours
WHERE total_cost = (SELECT MIN(total_cost) FROM v_all_tours)
   OR total_cost = (SELECT MAX(total_cost) FROM v_all_tours)
ORDER BY total_cost, tour;
```

Другой путь: два запроса (минимум и максимум), склеенных `UNION`, но тогда `ORDER BY` нужен один общий в конце.

Заметь: итоговый запрос ничего не знает про рекурсию. Всю сложность спрятало представление. Это и есть смысл разделения на «Навигатора» и «Архитектора»: интерфейс (`v_all_tours`) один, а внутри можно менять как угодно.

Ключевые слова для примеров: `MIN`, `MAX`, `UNION`, `ORDER BY`, `VIEW`.
