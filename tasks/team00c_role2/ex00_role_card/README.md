# Роль 2 · «Навигатор»: твоя карточка

Ты отвечаешь за **перебор маршрутов**: за рекурсивный запрос, который строит все пути по графу. Твой напарник (Роль 1, «Архитектор графа») создаёт таблицу рёбер `nodes` и делает итоговые выборки по твоему результату.

## Твои задания (в левом списке по порядку)

1. **ex01. Все маршруты**: создай представление `v_all_tours` с помощью `WITH RECURSIVE`.
2. **ex02. Обратная задача**: из всех маршрутов выбери самые дешёвые **и** самые дорогие (задание 01 проекта).
3. **ex03. Старт из любого города**: оформи запрос как функцию с параметром.

## Что тебе нужно от напарника

Таблица `nodes(point1, point2, cost)`: рёбра графа в **обе стороны**. В тренажёре она уже подготовлена для твоих заданий.

## Что отдать напарнику

Скрипт `CREATE VIEW v_all_tours` (ex01). Столбцы строго: `total_cost` (суммарная стоимость), `tour` (массив городов, маршрут начинается и заканчивается в `a`).

## Как проверить себя вместе

Напарник запускает свой запрос выбора минимума по твоему представлению: должно получиться 2 маршрута по 80.
