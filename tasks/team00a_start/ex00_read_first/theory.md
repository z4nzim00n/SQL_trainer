# Теория: что общего у обеих ролей

## Граф как таблица

Граф хранят таблицей рёбер: «из какой вершины, в какую вершину, какая стоимость». Если дороги двусторонние, в таблицу вносят **обе** строки: `(a, b, 10)` и `(b, a, 10)`. Тогда запрос «куда можно поехать из города X» это просто `WHERE point1 = 'X'`.

## Маршрут как массив

Маршрут удобно хранить массивом: `ARRAY['a','b','d','c','a']`, на экране `{a,b,d,c,a}`. С массивами нужны три приёма:

- `путь || город`: дописать город в конец массива;
- `город = ANY (путь)`: проверить, что город уже есть в пути;
- `CARDINALITY(путь)`: длина массива.

## Рекурсивный запрос

Перебор маршрутов делается рекурсивным запросом `WITH RECURSIVE`. Он состоит из двух частей, соединённых `UNION ALL`:

1. **стартовая часть**: первые шаги (из города `a` в любой другой);
2. **рекурсивная часть**: как продлить уже найденный путь на один шаг. Работает, пока есть что продлевать.

Запрос повторяет рекурсивную часть, подставляя в неё строки, найденные на прошлом шаге, и останавливается, когда новых строк нет.

Ключевые слова для примеров: `CTE`, `WITH`, `UNION ALL`, `JOIN`.
