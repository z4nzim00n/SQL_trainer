## Идея

Распределите роли и договоритесь об именах из таблицы-контракта. После этого у каждого своя работа.

## Каркас

1. Роль 1 создаёт `nodes`.
2. Роль 2 создаёт `v_all_tours` (по таблице `nodes`).
3. Роль 1 делает итоговые выборки по `v_all_tours`.
4. Вместе делаете общую сборку.

## Почти ответ

Начните с таблицы `nodes`: она нужна обоим. В тренажёре её уже подготовили для Навигатора, но в реальном проекте Навигатор ждёт скрипт Архитектора.
