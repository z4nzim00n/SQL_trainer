# 1. SELECT: основы запроса

Запрос `SELECT` только **читает** данные и ничего не меняет. Он отвечает на три вопроса: какие столбцы показать, из какой таблицы и какие строки оставить.

Все примеры в энциклопедии работают на учебной базе пиццерий: `person`, `pizzeria`, `menu`, `person_visits`, `person_order`. Схему смотри на вкладке «Схема БД» в окне с запросом. Под каждым примером есть кнопка «Показать пример»: она выполняет запрос на настоящем PostgreSQL.

## Минимальный запрос

```sql
SELECT столбцы
FROM таблица;
```

```sql-run
SELECT name, age
FROM person;
```

Звёздочка `*` означает «все столбцы». Для быстрого взгляда на таблицу удобно, в готовых решениях лучше перечислять столбцы явно.

```sql-run
SELECT *
FROM pizzeria;
```

## Порядок слов

Слова пишутся строго в таком порядке, хотя не все обязательны:

```sql
SELECT ...      -- что показать
FROM ...        -- откуда
WHERE ...       -- какие строки оставить
GROUP BY ...    -- сгруппировать
HAVING ...      -- отфильтровать группы
ORDER BY ...    -- отсортировать
LIMIT ...;      -- ограничить число строк
```

А **выполняет** база их в другом порядке: `FROM` → `WHERE` → `GROUP BY` → `HAVING` → `SELECT` → `ORDER BY` → `LIMIT`. Отсюда два важных следствия:

- в `WHERE` нельзя использовать новое имя столбца, придуманное в `SELECT` через `AS` (оно ещё не существует);
- в `ORDER BY` новое имя использовать можно (к этому моменту `SELECT` уже выполнен).

## AS: новые имена

`AS` переименовывает столбец в результате. Исходная таблица не меняется.

```sql-run
SELECT name AS person_name, age AS years
FROM person;
```

Если имя содержит пробелы или заглавные буквы, берут двойные кавычки: `AS "Person Name"`. Слово `AS` можно опустить (`name person_name`), но с ним читается понятнее.

**Псевдонимы таблиц** укорачивают запись, особенно в `JOIN`. Они обязательны, когда одну таблицу нужно взять дважды:

```sql-run
SELECT p.name, p.age
FROM person AS p;
```

Если псевдоним задан, то писать полное имя таблицы (`person.name`) уже нельзя: только `p.name`.

## Выражения в SELECT

В `SELECT` можно считать:

```sql-run
SELECT pizza_name, price, price * 0.9 AS price_with_discount, price + 50 AS price_plus_50
FROM menu;
```

Есть арифметика `+ - * /` и остаток `%`. Целочисленное деление округляет вниз: `7 / 2` даёт `3`, а `7 / 2.0` даёт `3.5`.

```sql-run
SELECT 7 / 2 AS int_division, 7 / 2.0 AS decimal_division, 7 % 2 AS remainder;
```

`SELECT` можно использовать и без `FROM`, чтобы просто вычислить значение.

## DISTINCT: убрать повторы

`DISTINCT` оставляет только уникальные строки результата. Уникальность считается по **всей строке** (по всем выбранным столбцам вместе).

```sql-run
SELECT DISTINCT pizza_name
FROM menu;
```

```sql-run
SELECT DISTINCT pizzeria_id, pizza_name
FROM menu;
```

Во втором примере повтором считается совпадение пары «пиццерия + название», а не одного столбца. Сравни с количеством строк в `SELECT pizza_name FROM menu`.

## ORDER BY: сортировка

Без `ORDER BY` порядок строк **не гарантирован**: база вправе вернуть их как угодно. Если порядок важен, пиши `ORDER BY`.

```sql-run
SELECT name, age
FROM person
ORDER BY age DESC;
```

- `ASC` по возрастанию (по умолчанию), `DESC` по убыванию.
- Столбцов может быть несколько: сначала сортировка по первому, при равенстве по второму и так далее. У каждого столбца свой `ASC/DESC`.
- Можно сортировать по номеру столбца в `SELECT`: `ORDER BY 2`.
- Можно сортировать по выражению: `ORDER BY price * 2`.

```sql-run
SELECT name, age, address
FROM person
ORDER BY address ASC, age DESC;
```

**Регистр букв.** Порядок текста зависит от правил сортировки (collation) базы. В одной базе заглавные идут раньше строчных, в другой нет. Не рассчитывай на конкретный порядок разных регистров.

**NULL при сортировке.** В `ASC` значения `NULL` идут в конце, в `DESC` в начале. Это можно поменять: `ORDER BY address NULLS FIRST` или `NULLS LAST`.

## LIMIT и OFFSET

`LIMIT n` берёт первые `n` строк, `OFFSET m` пропускает `m` строк сначала. Пара часто нужна для «топ-3» и постраничного вывода. Без `ORDER BY` они бессмысленны: непонятно, какие строки «первые».

```sql-run
SELECT name, age
FROM person
ORDER BY age DESC
LIMIT 3;
```

```sql-run
SELECT name, age
FROM person
ORDER BY age DESC
LIMIT 3 OFFSET 3;
```

В стандарте SQL то же пишется `FETCH FIRST 3 ROWS ONLY`, и PostgreSQL это понимает.

## Типичные ошибки

- Забытая запятая между столбцами или лишняя запятая перед `FROM`.
- Двойные кавычки вместо одинарных вокруг текста (`"Moscow"` это имя столбца, а текст пишется `'Moscow'`).
- Алиас из `SELECT` в `WHERE`.
- Точка с запятой пропущена между двумя запросами.
