# Учебные мини-таблицы (для примеров)

`a(id, val)` и `b(id, val)` для операторов множеств, `courses(id, title)` и `students(id, name, age, city, course_id)` для JOIN, `products(id, title, category, price, added, note)` для WHERE, типов и DML, `sales(id, shop, item, qty, price, sale_date)` для агрегатов и оконных функций.
